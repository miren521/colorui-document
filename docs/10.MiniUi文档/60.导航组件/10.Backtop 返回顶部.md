# m-backtop 返回顶部

用于长页面快速返回顶部的悬浮按钮组件，支持自定义位置、形状、显示阈值及滚动动画时长。需配合页面滚动事件手动传入 `scrollTop` 值以控制显隐。

## 基本用法

```vue
<template>
  <m-backtop :scroll-top="scrollTop" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { onPageScroll } from '@dcloudio/uni-app'
import mBacktop from '@/packages/m-backtop/m-backtop.vue'

const scrollTop = ref(0)

onPageScroll((event) => {
  scrollTop.value = event.scrollTop
})
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| scroll-top | 当前页面滚动距离，**必传**，用于判断是否显示按钮 | number | - |
| top | 滚动距离超过该值时显示按钮，单位 px | number | `300` |
| bottom | 按钮距离屏幕底部的距离，单位 px | number | `100` |
| right | 按钮距离屏幕右侧的距离，单位 px | number | `20` |
| duration | 点击后返回顶部的滚动动画时长，单位 ms | number | `100` |
| shape | 按钮形状 | `'circle' \| 'square'` | `'circle'` |
| effect | 外观效果 | `'border' \| 'no-border' \| 'floating'` | `'floating'` |
| text | 按钮下方提示文字，为空时不显示 | string | 源码中未明确说明 |
| color | 图标和文字颜色 | string | `'#666666'` |
| z-index | 按钮层级 | number | `10` |
| icon-style | 自定义图标样式 | string | `''` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| click | 点击按钮时触发，在调用 `pageScrollTo` 之前触发 | - |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 自定义按钮内容，传入后内置图标和文字不再渲染 |

## 方法（Methods）

源码中未通过 ref 暴露任何方法。

## 完整示例

```vue
<template>
  <!-- 基础用法 -->
  <m-backtop :scroll-top="scrollTop" />

  <!-- 自定义形状与文本 -->
  <m-backtop
    :scroll-top="scrollTop"
    shape="square"
    text="顶部"
    :bottom="120"
    :right="30"
  />

  <!-- 自定义颜色与外观 -->
  <m-backtop
    :scroll-top="scrollTop"
    color="#ffffff"
    effect="border"
    custom-style="background-color: #1989fa"
  />

  <!-- 自定义阈值与动画时长 -->
  <m-backtop
    :scroll-top="scrollTop"
    :top="500"
    :duration="500"
  />

  <!-- 自定义内容插槽 -->
  <m-backtop :scroll-top="scrollTop">
    <view class="custom-backtop">↑</view>
  </m-backtop>

  <!-- 监听点击事件 -->
  <m-backtop :scroll-top="scrollTop" @click="onBacktopClick" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { onPageScroll } from '@dcloudio/uni-app'
import mBacktop from '@/packages/m-backtop/m-backtop.vue'

const scrollTop = ref(0)

onPageScroll((event) => {
  scrollTop.value = event.scrollTop
})

function onBacktopClick() {
  console.log('用户点击了返回顶部')
}
</script>

<style scoped lang="scss">
.custom-backtop {
  width: 40px;
  height: 40px;
  border-radius: 50%;
  background-color: #1989fa;
  color: #fff;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 20px;
}
</style>
```

## 注意事项

1.  **scrollTop 必传**：组件不会自动监听页面滚动，必须通过 `onPageScroll` 获取滚动距离并传入 `scroll-top`，否则按钮永远不会显示。
2.  **滚动 API**：点击按钮后内部调用 `uni.pageScrollTo({ scrollTop: 0, duration })` 实现滚动，该 API 仅对页面级滚动生效；若内容在 `scroll-view` 内滚动，需自行处理滚动逻辑并通过插槽替换默认行为。
3.  **显隐动画**：组件使用 `m-transition` 实现淡入淡出效果，依赖 `m-transition` 组件的 `fade` 动画名称，确保项目中已正确引入该组件。
4.  **平台差异**：组件 options 中使用了 `virtualHost: true`，该选项在头条小程序（MP-TOUTIAO）下被条件编译排除，头条小程序中组件会保留自身节点；其他平台虚拟宿主节点生效。
5.  **定位方式**：按钮使用固定定位（`position: fixed`），`bottom` 和 `right` 单位为 px，不支持 rpx 或其他单位。
6.  **iconStyle 未使用**：types 中定义了 `iconStyle` 属性，但当前模板未将其绑定到 `m-icon` 组件，实际不会生效。如需自定义图标样式请通过 `custom-style` 或 CSS 覆盖。
7.  **z-index 冲突**：默认 `z-index` 为 10，若页面存在其他高 zIndex 元素可能导致按钮被遮挡，建议根据实际情况调高该值。
8.  **背景色定制**：组件未提供独立的背景色 prop，需通过 `custom-style` 传入 `background-color` 来修改按钮背景。
