# m-avatar 头像

用于展示用户头像、图标或文本标识，支持图片、文字、图标三种内容形式，可配置尺寸、形状、状态徽标等。通常与 `m-avatar-group` 配合使用以展示头像列表。

## 基本用法

```vue
<template>
  <m-avatar shape="round" src="/static/img/avatar.jpg" />
  <m-avatar shape="round" text="张" />
  <m-avatar shape="round" icon="user" />
</template>

<script setup lang="ts">
import mAvatar from '@/packages/m-avatar/m-avatar.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| src | 图片地址 | string | `''` |
| text | 文本内容，优先级低于 src | string | `''` |
| icon | 图标名称，对应 m-icon 的 name，优先级低于 src 和 text | string | `''` |
| size | 头像尺寸，支持预设值 `'large' \| 'medium' \| 'normal' \| 'small'` 或自定义数值/带单位字符串（如 `40`、`'100rpx'`） | string \| number | `'normal'` |
| shape | 头像形状 | `'round' \| 'square'` | `'round'` |
| color | 文字/图标颜色 | string | `''` |
| bg-color | 背景颜色，设置后若未设置 color 则文字默认为白色 | string | `''` |
| mode | 图片填充模式，同 uni-app image 组件的 mode | ImageMode | `'aspectFill'` |
| alt | 图片加载失败时的占位文本 | string | `''` |
| status | 状态徽标类型 | `'online' \| 'offline' \| 'busy' \| 'vip'` | `''` |
| status-position | 状态徽标位置 | `'top-right' \| 'bottom-right'` | `'top-right'` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

> `_internal` 为组件内部属性，用于 avatar-group 溢出计数头像，业务代码请勿使用。

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| click | 点击头像时触发 | - |
| load | 图片加载成功时触发 | event: Event |
| error | 图片加载失败时触发 | event: Event |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 自定义头像内容，传入后优先渲染，src / text / icon 将失效 |
| status-icon | 自定义状态徽标图标，传入后内置状态点样式失效 |

## 注意事项

1.  **内容优先级**：默认插槽 > `src` > `text` > `icon`，同时传入多个内容时仅渲染优先级最高的一个。
2.  **尺寸继承**：在 `m-avatar-group` 内使用时，若子组件未单独设置 `size` / `shape`，会自动继承父组件的对应属性。
3.  **自定义尺寸**：传入非预设值（如数字 `40` 或字符串 `'100rpx'`）时，组件会通过内联样式设置宽高，字号按尺寸的 0.45 倍自动计算。
4.  **平台差异**：组件 options 中使用了 `virtualHost: true`，该选项在头条小程序（MP-TOUTIAO）下被条件编译排除，头条小程序中组件会保留自身节点；其他平台虚拟宿主节点生效，外层不会生成额外 DOM。
5.  **状态徽标**：`status` 仅在未使用 `status-icon` 插槽时渲染内置状态点；使用插槽后内置状态点不再显示，需自行控制徽标样式与定位。
6.  **头像组溢出**：`m-avatar-group` 设置 `maxCount` 后，超出数量的头像会被隐藏并自动生成折叠计数头像；折叠头像的位置受 `cascading` 属性影响，`left-up` 时置于最左侧，其余情况置于最右侧。
7.  **alt 属性**：源码中定义了 `alt` prop，但当前模板未将其绑定到 `m-img` 组件，实际不会生效，如需图片替代文本请通过 `error` 事件自行处理。

# m-avatar-group 头像组

用于将多个 `m-avatar` 组合展示，支持限制最大显示数量、设置层叠方向和垂直布局。

## 基本用法

```vue
<template>
  <m-avatar-group>
    <m-avatar shape="round" src="/static/img/img_1.jpg" />
    <m-avatar shape="round" src="/static/img/img_2.jpg" />
    <m-avatar shape="round" src="/static/img/img_3.jpg" />
  </m-avatar-group>
</template>

<script setup lang="ts">
import mAvatar from '@/packages/m-avatar/m-avatar.vue'
import mAvatarGroup from '@/packages/m-avatar-group/m-avatar-group.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| max-count | 最多显示的头像数量，超出部分自动折叠为计数头像 | number | 源码中未明确说明（undefined） |
| cascading | 头像层叠方向，`left-up` 左侧在上，`right-up` 右侧在上 | `'left-up' \| 'right-up'` | `'right-up'` |
| vertical | 是否垂直排列 | boolean | 源码中未明确说明（false） |
| collapse-avatar | 自定义折叠头像文本，不传时默认显示 `+N` | string | 源码中未明确说明（`+${restCount}`） |
| size | 统一设置子头像尺寸，子组件单独设置时以子组件为准 | string \| number | 源码中未明确说明 |
| shape | 统一设置子头像形状，子组件单独设置时以子组件为准 | `'round' \| 'square'` | 源码中未明确说明 |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

## 事件（Events）

源码中未定义任何事件。

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 放置 `m-avatar` 子组件 |

  <!-- 基础用法 -->

      <m-avatar shape="round" src="/static/img/img_1.jpg" />
      <m-avatar shape="round" src="/static/img/img_2.jpg" />
      <m-avatar shape="round" src="/static/img/img_3.jpg" />

  <m-avatar-group cascading="left-up" vertical>

## 注意事项

1.  **子组件限制**：默认插槽内应只放置 `m-avatar` 组件，放入其他元素可能导致层叠、溢出计数等逻辑异常。
2.  **属性继承**：`size` 和 `shape` 会向下传递给子 `m-avatar`，子组件单独设置同名属性时以子组件值为准。
3.  **折叠头像**：当子组件数量超过 `maxCount` 时自动生成折叠计数头像，其 z-index 始终最高以保证可见；折叠头像的背景色固定为 `#ebedf0`，文字色固定为 `#969799`，不可通过 props 修改。
4.  **层叠方向**：`left-up` 时最左侧头像在最上层，折叠头像也置于最左；`right-up` 时最右侧头像在最上层，折叠头像置于最右。
5.  **垂直布局**：设置 `vertical` 后头像改为纵向排列，层叠负边距方向同步切换为 marginTop。
6.  **平台差异**：与 `m-avatar` 相同，`virtualHost: true` 在头条小程序下被排除，其他平台生效。
7.  **maxCount 校验**：传入非正数或非数字时视为未设置，所有子头像均正常显示，不会生成折叠头像。
