# m-badge 徽标

用于在元素右上角展示数字、文字或小红点的标记组件，支持最大值截断、零值显示、多种类型与形状，可独立使用也可包裹子元素。

## 基本用法

```vue
<template>
  <m-badge value="8">
    <view class="btn">消息</view>
  </m-badge>

  <m-badge value="0" show-zero>
    <view class="btn">零值</view>
  </m-badge>

  <!-- 独立使用 -->
  <m-badge value="123" />
</template>

<script setup lang="ts">
import mBadge from '@/packages/m-badge/m-badge.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| value | 徽标显示内容，支持数字或字符串 | string \| number | 源码中未明确说明 |
| max | 最大值，当 `value` 为数字且超过该值时显示 `{max}+` | number | 源码中未明确说明 |
| show-zero | 当 `value` 为 0 时是否仍然显示徽标 | boolean | `false` |
| is-dot | 是否显示为小红点，开启后不显示任何文本内容 | boolean | `false` |
| hidden | 是否隐藏徽标 | boolean | `false` |
| type | 徽标颜色类型 | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'info'` | 源码中未明确说明 |

| bg-color | 自定义背景颜色，优先级高于 `type` | string | 源码中未明确说明 |

| right | 徽标水平偏移量，正数向左偏移，负数向右偏移 | string \| number | 源码中未明确说明 |

## 注意事项

1.  **显隐逻辑**：徽标仅在以下条件同时满足时渲染：`hidden` 为 `false`，且 (`content` 有值 || `content === 0 && showZero` || `isDot`)。不满足时整个徽标节点不会出现在 DOM 中。
2.  **max 截断规则**：仅当 `value` 和 `max` 均可转换为有效数字时才生效；若任一为非数字字符串，则直接原样显示 `value`，不做截断处理。
3.  **is-dot 优先级**：开启 `is-dot` 后，无论 `value` 为何值，徽标内容始终为空字符串，仅渲染圆点样式。
4.  **bg-color 覆盖 type**：同时设置 `bg-color` 和 `type` 时，`bg-color` 的内联样式优先级更高，会覆盖 `type` 对应的主题色。
5.  **偏移方向**：`top` 正值向下偏移、负值向上偏移；`right` 正值向左偏移、负值向右偏移。这与 CSS `top`/`right` 属性的语义一致，使用时注意方向。
6.  **独立使用定位**：不包裹子元素独立使用时，徽标仍带有 `is-fixed` 类名（绝对定位），需确保父容器具有相对定位或其他定位上下文，否则徽标可能脱离预期位置。Demo 中通过负的 `right` 值将独立徽标拉回可视区域。
7.  **平台差异**：组件 options 中使用了 `virtualHost: true`，该选项在头条小程序（MP-TOUTIAO）下被条件编译排除，头条小程序中组件保留自身节点；其他平台虚拟宿主节点生效，外层不生成额外 DOM。
8.  **border 样式依赖**：`border` 属性添加 `is-border` 类名，具体描边样式由外部 SCSS 文件定义，若自定义主题时需确保对应样式已正确引入。
