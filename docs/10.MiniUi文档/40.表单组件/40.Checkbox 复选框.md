# m-checkbox 复选框

`m-checkbox` 是复选框组件，支持单独使用或配合 `m-checkbox-group` 组合使用。提供多种形状、自定义颜色、不确定状态、禁用/只读等功能，适用于表单选择、列表多选等场景。

## 基本用法

单独使用时通过 `v-model` 绑定布尔值；组合使用时通过 `m-checkbox-group` 管理选中状态，绑定数组值。

```vue
<template>
  <!-- 单独使用 -->
  <m-checkbox v-model="checked">同意协议</m-checkbox>

  <!-- 组合使用 -->
  <m-checkbox-group v-model="fruits">
    <m-checkbox name="apple">苹果</m-checkbox>
    <m-checkbox name="banana">香蕉</m-checkbox>
    <m-checkbox name="orange">橙子</m-checkbox>
  </m-checkbox-group>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const checked = ref(false)
const fruits = ref(['apple'])
</script>
```

## 属性（Props）

### m-checkbox

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中值，单独使用时绑定 | `string \| number \| boolean` | `false` |
| name | 标识符，在 checkbox-group 中必填 | `string \| number \| boolean` | `''` |
| type | 图标形状 | `'circle' \| 'square' \| 'dot'` | `'square'` |
| checkedColor | 选中状态颜色 | `string` | - |
| uncheckedColor | 未选中状态颜色 | `string` | - |
| disabled | 是否禁用，null 时继承 group 设置 | `boolean \| null` | `null` |
| indeterminate | 是否为不确定状态（半选） | `boolean` | `false` |
| readonly | 是否只读，null 时继承 group 设置 | `boolean \| null` | `null` |
| trueValue | 选中时的值 | `string \| number \| boolean` | `true` |
| falseValue | 未选中时的值 | `string \| number \| boolean` | `false` |
| size | 图标尺寸 | `string` | - |
| maxWidth | 文字最大宽度 | `string` | - |
| placement | 文字位置 | `'left' \| 'right'` | - (继承 group 或 `'left'`) |
| direction | 排列方向 | `'horizontal' \| 'vertical'` | - (继承 group 或 `'vertical'`) |
| customLabelClass | 自定义文字区域类名 | `string` | - |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |

### m-checkbox-group

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中项的值数组 | `(string \| number \| boolean)[]` | `[]` |
| type | 统一设置图标形状 | `'circle' \| 'square' \| 'dot'` | `'square'` |
| checkedColor | 统一设置选中颜色 | `string` | - |
| uncheckedColor | 统一设置未选中颜色 | `string` | - |
| disabled | 是否禁用全部子项 | `boolean` | `false` |
| readonly | 是否只读全部子项 | `boolean` | `false` |
| min | 最少选中数量，0 表示不限制 | `number` | `0` |
| max | 最多选中数量，0 表示不限制 | `number` | `0` |
| size | 统一设置图标尺寸 | `string` | - |
| placement | 统一设置文字位置 | `'left' \| 'right'` | `'left'` |
| direction | 排列方向 | `'horizontal' \| 'vertical'` | `'vertical'` |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |

## 事件（Events）

### m-checkbox

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| change | 选中状态变化时触发（仅单独使用时） | `{ value: string \| number \| boolean }` |
| update:modelValue | 双向绑定更新 | `string \| number \| boolean` |

### m-checkbox-group

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| change | 选中项变化时触发 | `{ value: (string \| number \| boolean)[] }` |
| update:modelValue | 双向绑定更新 | `(string \| number \| boolean)[]` |

## 插槽（Slots）

### m-checkbox

| 插槽名 | 说明 | 作用域参数 |
| :--- | :--- | :--- |
| default | 复选框文字内容 | - |
| icon | 自定义图标 | `{ isChecked: boolean }` |

### m-checkbox-group

| 插槽名 | 说明 |
| :--- | :--- |
| default | 放置 m-checkbox 子组件 |

## 方法（Methods）

### m-checkbox

通过 `ref` 获取组件实例后可调用：

| 方法名 | 说明 | 参数 |
| :--- | :--- | :--- |
| toggle | 切换选中状态 | - |

### m-checkbox-group

通过 `ref` 获取组件实例后可调用：

| 方法名 | 说明 | 参数 |
| :--- | :--- | :--- |
| toggleAll | 全选/取消全选/反选 | `options?: boolean \| { checked?: boolean, skipDisabled?: boolean }` |

`toggleAll` 参数说明：
-   传入 `true`：全选
-   传入 `false`：取消全选
-   不传参或 `undefined`：反选
-   传入对象 `{ checked, skipDisabled }`：`skipDisabled` 为 `true` 时跳过禁用项

## 完整示例

```vue
<template>
  <view class="demo-container">
    <!-- 基础用法 + 自定义值 -->
    <m-checkbox v-model="basicChecked">基础复选框</m-checkbox>
    <m-checkbox v-model="customVal" true-value="yes" false-value="no">同意协议</m-checkbox>

    <!-- 复选框组 + 水平布局 + 限制数量 -->
    <m-checkbox-group v-model="groupVal" direction="horizontal" :min="1" :max="2">
      <m-checkbox name="a">选项A</m-checkbox>
      <m-checkbox name="b">选项B</m-checkbox>
      <m-checkbox name="c" disabled>选项C（禁用）</m-checkbox>
    </m-checkbox-group>

    <!-- 不同形状 + 自定义颜色 -->
    <m-checkbox v-model="shapeCircle" type="circle" checked-color="#ff6b6b">圆形红色</m-checkbox>
    <m-checkbox v-model="shapeDot" type="dot">点状</m-checkbox>

    <!-- 不确定状态 -->
    <m-checkbox v-model="allChecked" :indeterminate="isIndeterminate" @change="onAllChange">全选</m-checkbox>
    <m-checkbox-group v-model="subItems">
      <m-checkbox name="s1">子项1</m-checkbox>
      <m-checkbox name="s2">子项2</m-checkbox>
      <m-checkbox name="s3">子项3</m-checkbox>
    </m-checkbox-group>

    <!-- toggleAll 方法 -->
    <m-checkbox-group v-model="toggleVal" ref="groupRef">
      <m-checkbox name="t1">选项1</m-checkbox>
      <m-checkbox name="t2">选项2</m-checkbox>
      <m-checkbox name="t3">选项3</m-checkbox>
    </m-checkbox-group>
    <view class="actions">
      <button @click="groupRef?.toggleAll(true)">全选</button>
      <button @click="groupRef?.toggleAll(false)">取消</button>
      <button @click="groupRef?.toggleAll()">反选</button>
      <button @click="groupRef?.toggleAll({ checked: true, skipDisabled: true })">全选(跳过禁用)</button>
    </view>

    <!-- 自定义图标插槽 -->
    <m-checkbox v-model="slotChecked">
      <template #icon="{ isChecked }">
        <text>{{ isChecked ? '✅' : '⬜' }}</text>
      </template>
      自定义图标
    </m-checkbox>
  </view>
</template>

<script setup lang="ts">
import { ref, watch } from 'vue'

const basicChecked = ref(false)
const customVal = ref('no')
const groupVal = ref(['a'])
const shapeCircle = ref(true)
const shapeDot = ref(false)
const slotChecked = ref(false)

// 不确定状态逻辑
const allChecked = ref(false)
const isIndeterminate = ref(false)
const subItems = ref<string[]>([])

watch(subItems, (val) => {
  if (val.length === 0) { allChecked.value = false; isIndeterminate.value = false }
  else if (val.length === 3) { allChecked.value = true; isIndeterminate.value = false }
  else { allChecked.value = false; isIndeterminate.value = true }
})

function onAllChange({ value }) {
  isIndeterminate.value = false
  subItems.value = value ? ['s1', 's2', 's3'] : []
}

// toggleAll
const toggleVal = ref([])
const groupRef = ref()
</script>
```

## 注意事项

1.  **name 必填**：在 `m-checkbox-group` 内使用时，每个 `m-checkbox` 必须设置唯一的 `name` 属性，否则控制台会输出警告且无法正常工作。
2.  **modelValue 类型**：单独使用时默认为布尔值，可通过 `trueValue` / `falseValue` 自定义；组合使用时 `m-checkbox-group` 的 `modelValue` 必须为数组，且不应包含重复值。
3.  **min/max 限制**：当选中数量达到 `max` 时，未选中项会自动变为禁用状态；当选中数量等于 `min` 时，已选中项会自动变为禁用状态，防止取消选中。
4.  **属性继承**：`m-checkbox` 的 `type`、`checkedColor`、`uncheckedColor`、`disabled`、`readonly`、`placement`、`direction` 属性若未设置（或为 `null`），会自动继承父级 `m-checkbox-group` 的对应属性。
5.  **indeterminate 状态**：不确定状态仅为视觉展示，不影响实际的 `modelValue` 值，需开发者自行根据子项选中情况维护该状态。
6.  **change 事件差异**：`m-checkbox` 的 `change` 事件仅在单独使用时触发；在 `m-checkbox-group` 内使用时，应监听 `m-checkbox-group` 的 `change` 事件。
7.  **toggleAll 的 skipDisabled**：设为 `true` 时，禁用状态的子项不会被全选/取消全选操作影响，保持原有选中状态。
8.  **平台兼容性**：组件使用了 `virtualHost: true`，头条小程序不支持该特性，源码中未做条件编译排除，在头条小程序下可能出现样式异常。
