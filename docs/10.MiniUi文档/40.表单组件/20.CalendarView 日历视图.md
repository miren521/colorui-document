# m-calendar-view 日历视图

`m-calendar-view` 是一个内嵌式日历面板组件，不包含弹出层逻辑，直接在页面中渲染日历内容。支持单日、多日、日期范围、时间、周、月等多种选择模式，适用于需要将日历嵌入表单或自定义弹窗的场景。

## 基本用法

通过 `v-model` 绑定选中值（13位时间戳），使用 `type` 指定选择类型。组件直接渲染在页面中，无需手动打开。

```vue
<template>
  <view>
    <m-calendar-view
      v-model="dateValue"
      type="date"
      @change="onChange"
    />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const dateValue = ref<number | null>(Date.now())

function onChange({ value }) {
  console.log('选中日期:', new Date(value))
}
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中值，为 13 位时间戳或时间戳数组 | `number \| number[] \| null` | - (必填) |
| type | 日期选择类型 | `'date' \| 'dates' \| 'datetime' \| 'week' \| 'month' \| 'daterange' \| 'datetimerange' \| 'weekrange' \| 'monthrange'` | `'date'` |
| minDate | 最小可选日期，13 位时间戳 | `number` | 当前日期前一年同日 |
| maxDate | 最大可选日期，13 位时间戳 | `number` | 当前日期后一年同日 |
| firstDayOfWeek | 周起始天，0 表示周日 | `number` | `0` |
| formatter | 日期格式化函数，自定义日期单元格显示 | `(day: CalendarDayItem) => CalendarDayItem` | - |
| maxRange | 范围选择时的最大跨度天数 | `number` | - |
| rangePrompt | 超出最大范围时的提示文案 | `string` | - |
| allowSameDay | 范围选择时是否允许起止为同一天 | `boolean` | `false` |
| showPanelTitle | 是否展示面板顶部月份/年份标题 | `boolean` | `true` |
| defaultTime | 选中日期所使用的当日内具体时刻 | `string \| string[]` | `'00:00:00'` |
| panelHeight | 可滚动面板高度（px） | `number` | `316` |
| timeFilter | 时间选择器数据过滤函数，仅 datetime/datetimerange 有效 | `(type: string, options: { label, value }[]) => { label, value }[]` | - |
| timeItemHeight | 时间选择器单项高度（px） | `number` | `44` |
| timeVisibleItemCount | 时间选择器可见项数 | `number` | `3` |
| hideSecond | 是否隐藏秒选择，仅 datetime/datetimerange 有效 | `boolean` | `false` |
| immediateChange | 手指松开时立即触发 change，仅微信/支付宝小程序支持 | `boolean` | `false` |
| switchMode | 月份/年份切换模式 | `'none' \| 'month' \| 'year-month'` | `'none'` |
| showHeader | 是否显示头部 | `boolean` | `true` |
| showYearView | 是否显示年份视图 | `boolean` | `false` |
| itemHeight | 日期/月份项高度（px） | `number` | `64` |
| visibleItemCount | 可见日期/月份项数 | `number` | `6` |
| timeFormatter | 时间选项格式化函数 | `(type: string, value: string) => string` | - |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |

## 完整示例

以下示例覆盖常用选择模式及配置项：

```vue
<template>
  <view class="demo-container">
    <!-- 基础日期选择 -->
    <view class="card" v-if="showDate">
      <m-calendar-view v-model="dateValue" type="date" @change="onDateChange" />
    </view>
    <m-cell title="选择日期" :value="dateLabel || '请选择'" clickable @click="showDate = !showDate" />

    <!-- 日期范围选择 -->
    <view class="card" v-if="showRange">
      <m-calendar-view v-model="rangeValue" type="daterange" :max-range="7" range-prompt="最多选7天" allow-same-day @change="onRangeChange" />
    </view>
    <m-cell title="日期范围" :value="rangeLabel || '请选择'" clickable @click="showRange = !showRange" />

    <!-- 月份选择 + 年月切换 -->
    <view class="card" v-if="showMonth">
      <m-calendar-view v-model="monthValue" type="month" switch-mode="year-month" @change="onMonthChange" />
    </view>
    <m-cell title="月份选择" :value="monthLabel || '请选择'" clickable @click="showMonth = !showMonth" />

    <!-- 自定义格式化 -->
    <view class="card" v-if="showCustom">
      <m-calendar-view v-model="customValue" type="date" :formatter="customFormatter" @change="onCustomChange" />
    </view>
    <m-cell title="自定义格式" :value="customLabel || '请选择'" clickable @click="showCustom = !showCustom" />
  </view>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import type { CalendarDayItem } from '@/packages/m-calendar-view/types'

const showDate = ref(false)
const showRange = ref(false)
const showMonth = ref(false)
const showCustom = ref(false)

const dateValue = ref<number | null>(Date.now())
const rangeValue = ref<(number | null)[]>([Date.now(), null])
const monthValue = ref<number | null>(Date.now())
const customValue = ref<number | null>(Date.now())

const dateLabel = computed(() => dateValue.value ? formatDate(dateValue.value) : '')
const rangeLabel = computed(() => {
  if (!rangeValue.value?.[0]) return ''
  if (!rangeValue.value?.[1]) return formatDate(rangeValue.value[0])
  return `${formatDate(rangeValue.value[0])} - ${formatDate(rangeValue.value[1])}`
})
const monthLabel = computed(() => {
  if (!monthValue.value) return ''
  const d = new Date(monthValue.value)
  return `${d.getFullYear()}年${d.getMonth() + 1}月`
})
const customLabel = computed(() => customValue.value ? formatDate(customValue.value) : '')

function formatDate(ts: number) {
  const d = new Date(ts)
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`
}

function customFormatter(day: CalendarDayItem): CalendarDayItem {
  const date = new Date(day.date)
  const dom = date.getDate()
  if (dom === 1) day.topInfo = '月初'
  else if (dom === new Date(date.getFullYear(), date.getMonth() + 1, 0).getDate()) day.topInfo = '月末'
  day.bottomInfo = dom % 2 === 0 ? '双日' : '单日'
  return day
}

function onDateChange({ value }) { dateValue.value = value }
function onRangeChange({ value }) { rangeValue.value = value }
function onMonthChange({ value }) { monthValue.value = value }
function onCustomChange({ value }) { customValue.value = value }
</script>

<style scoped>
.card { margin-bottom: 16rpx; border-radius: 12rpx; overflow: hidden; }
</style>
```

## 注意事项

1.  **与 m-calendar 的区别**：`m-calendar-view` 是纯面板组件，不含弹出层、确认按钮、遮罩等交互逻辑。如需弹窗形式请使用 `m-calendar`。
2.  **值类型**：`modelValue` 必须为 13 位毫秒级时间戳（`number`），范围类型为 `[number, number]` 数组，多日期为 `number[]`。传入非时间戳值可能导致异常。
3.  **平台差异**：
    -   `immediateChange` 仅在微信小程序和支付宝小程序生效，H5 和其他平台不支持。
    -   头条小程序不支持 `virtualHost`，源码中已做条件编译排除。
4.  **switchMode**：设为 `'month'` 时显示上/下月切换按钮；设为 `'year-month'` 时同时显示上/下年和上/下月按钮；设为 `'none'` 时平铺展示所有月份，不显示切换按钮。该属性对 `month` 和 `monthrange` 类型尤其重要。
5.  **formatter 函数**：接收 `CalendarDayItem` 对象并返回修改后的同一对象，不要返回新对象，否则可能导致状态丢失。可修改的字段包括 `topInfo`、`bottomInfo`、`customClass`、`disabled` 等。
6.  **defaultTime**：默认值为 `'00:00:00'`，范围类型可传数组分别指定起止时间，如 `['09:00:00', '18:00:00']`。
7.  **timeFilter / timeFormatter**：仅在 `datetime` 和 `datetimerange` 类型下生效，用于自定义时间选择器的选项过滤和显示文本。
8.  **scrollIntoView**：当面板初始渲染或外部修改了 `modelValue` 后，可能需要手动调用此方法使选中项滚动到可视区域。
