# m-datetime-picker 日期时间选择器

`m-datetime-picker` 是一个基于滚轮（Picker）的日期时间选择组件，以底部弹出层形式展示。支持日期、时间、日期时间、年月、年份等多种选择模式，并内置了日期范围选择功能。

> **注意**：此组件与 `m-calendar` 的区别在于交互形式。`m-datetime-picker` 采用滚轮选择，适合精确到时分秒的时间点选择；`m-calendar` 采用日历面板，适合日期范围和可视化日期选择。

## 基本用法

通过 `v-model` 绑定选中值，使用 `type` 指定选择类型。组件默认不自动弹出，需通过 `ref` 调用 `open()` 方法或设置 `visible` 属性控制显示。

```vue
<template>
  <view>
    <button @click="pickerRef?.open()">选择日期时间</button>
    <m-datetime-picker
      v-model="value"
      type="datetime"
      title="选择出发时间"
      ref="pickerRef"
      @confirm="onConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const value = ref<number>(Date.now())
const pickerRef = ref()

function onConfirm({ value }) {
  console.log('选中:', new Date(value))
}
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中值。非范围模式为时间戳或时间字符串；范围模式为 `[start, end]` 数组 | `string \| number \| (string \| number)[]` | - (必填) |
| type | 选择器类型 | `'datetime' \| 'date' \| 'time' \| 'year-month' \| 'year'` | `'datetime'` |
| minDate | 最小可选日期，13位时间戳 | `number` | 当前年份-10年1月1日 |
| maxDate | 最大可选日期，13位时间戳 | `number` | 当前年份+10年12月31日 |
| minHour | 最小可选小时（time/datetime 类型有效） | `number` | `0` |
| maxHour | 最大可选小时（time/datetime 类型有效） | `number` | `23` |
| minMinute | 最小可选分钟（time/datetime 类型有效） | `number` | `0` |
| maxMinute | 最大可选分钟（time/datetime 类型有效） | `number` | `59` |
| useSecond | 是否显示秒列（time/datetime 类型有效） | `boolean` | `false` |
| minSecond | 最小可选秒数 | `number` | `0` |
| maxSecond | 最大可选秒数 | `number` | `59` |
| title | 弹出层标题 | `string` | - |
| cancelButtonText | 取消按钮文案 | `string` | `'取消'` |
| confirmButtonText | 确认按钮文案 | `string` | `'确定'` |
| beforeConfirm | 确认前校验函数，返回 false 或 Promise\ 可阻止确认 | `(value) => boolean \| Promise<boolean>` | - |
| formatter | 选项文本格式化函数 | `(type: string, value: string) => string` | - |
| filter | 选项过滤函数，可隐藏特定选项 | `(type: string, values: number[]) => number[]` | - |
| displayFormatTabLabel | 范围模式下 Tab 标签的自定义格式化函数 | `(items: Record<string, any>[]) => string` | - |
| itemHeight | 单行选项高度（px） | `number` | `44` |
| visibleItemCount | 可见选项行数 | `number` | `6` |
| valueKey | 选项值字段名 | `string` | `'value'` |
| labelKey | 选项文本字段名 | `string` | `'label'` |
| closeOnClickModal | 点击遮罩层是否关闭弹窗 | `boolean` | `true` |
| safeAreaInsetBottom | 是否开启底部安全区适配 | `boolean` | `true` |
| zIndex | 弹窗层级 | `number` | `15` |
| immediateChange | 手指松开时立即触发 change，仅微信/支付宝小程序支持 | `boolean` | `false` |
| rootPortal | 是否从页面中脱离渲染，解决 fixed 定位失效问题 | `boolean` | `false` |
| visible | 控制弹窗显示/隐藏，支持 v-model:visible | `boolean` | `false` |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |
| customViewClass | 自定义内部 picker-view 类名 | `string` | `''` |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| confirm | 确认选择时触发 | `{ value: string \| number \| (string \| number)[] }` |
| cancel | 取消选择或关闭弹窗时触发 | - |
| change | 选中值变化时触发 | `{ value: string \| number \| (string \| number)[] }` |
| open | 弹窗打开时触发 | - |
| toggle | 范围模式下切换开始/结束 Tab 时触发 | `当前 Tab 对应的值` |
| update:modelValue | 双向绑定更新 | `string \| number \| (string \| number)[]` |
| update:visible | 弹窗可见性双向绑定更新 | `boolean` |

## 完整示例

```vue
<template>
  <view class="demo-container">
    <!-- 日期选择 -->
    <m-cell title="选择日期" :value="dateLabel || '请选择'" clickable @click="dateRef?.open()" />
    <m-datetime-picker
      v-model="dateValue"
      type="date"
      title="选择日期"
      ref="dateRef"
      @confirm="onDateConfirm"
    />

    <!-- 时间选择（含秒） -->
    <m-cell title="选择时间" :value="timeLabel || '请选择'" clickable @click="timeRef?.open()" />
    <m-datetime-picker
      v-model="timeValue"
      type="time"
      title="选择时间"
      use-second
      ref="timeRef"
      @confirm="onTimeConfirm"
    />

    <!-- 日期时间 + 自定义范围 + 自定义按钮 -->
    <m-cell title="出发时间" :value="dtLabel || '请选择'" clickable @click="dtRef?.open()" />
    <m-datetime-picker
      v-model="dtValue"
      type="datetime"
      title="出发时间"
      :min-date="minDate"
      :max-date="maxDate"
      cancel-button-text="算了"
      confirm-button-text="好的"
      :formatter="formatter"
      ref="dtRef"
      @confirm="onDtConfirm"
    />

    <!-- 日期范围选择 -->
    <m-cell title="日期范围" :value="rangeLabel || '请选择'" clickable @click="rangeRef?.open()" />
    <m-datetime-picker
      v-model="rangeValue"
      type="date"
      title="选择日期范围"
      ref="rangeRef"
      @confirm="onRangeConfirm"
    />

    <!-- 受控弹窗 -->
    <m-cell title="受控弹窗" :value="ctrlLabel || '请选择'" clickable @click="ctrlVisible = true" />
    <m-datetime-picker
      v-model="ctrlValue"
      type="datetime"
      v-model:visible="ctrlVisible"
      title="受控弹窗"
      @confirm="onCtrlConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'

const now = new Date()
const minDate = new Date(now.getFullYear(), now.getMonth(), 1).getTime()
const maxDate = new Date(now.getFullYear(), now.getMonth() + 3, 0, 23, 59, 59).getTime()

// 日期
const dateValue = ref<number>(Date.now())
const dateRef = ref()
const dateLabel = computed(() => dateValue.value ? formatDate(dateValue.value) : '')

// 时间
const timeValue = ref<string>('09:30:00')
const timeRef = ref()
const timeLabel = computed(() => timeValue.value || '')

// 日期时间
const dtValue = ref<number>(Date.now())
const dtRef = ref()
const dtLabel = computed(() => dtValue.value ? formatDatetime(dtValue.value) : '')

// 范围
const rangeValue = ref<(number | string)[]>([])
const rangeRef = ref()
const rangeLabel = computed(() => {
  if (!rangeValue.value?.[0] || !rangeValue.value?.[1]) return ''
  return `${formatDate(rangeValue.value[0])} ~ ${formatDate(rangeValue.value[1])}`
})

// 受控
const ctrlValue = ref<number>(Date.now())
const ctrlVisible = ref(false)
const ctrlLabel = computed(() => ctrlValue.value ? formatDatetime(ctrlValue.value) : '')

function formatDate(ts: string | number) {
  const d = new Date(ts)
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`
}

function formatDatetime(ts: string | number) {
  const d = new Date(ts)
  return `${formatDate(ts)} ${String(d.getHours()).padStart(2, '0')}:${String(d.getMinutes()).padStart(2, '0')}`
}

function formatter(type: string, value: string): string {
  const suffixMap: Record<string, string> = { year: '年', month: '月', date: '日', hour: '时', minute: '分', second: '秒' }
  return `${value}${suffixMap[type] || ''}`
}

function onDateConfirm({ value }) { dateValue.value = value }
function onTimeConfirm({ value }) { timeValue.value = value }
function onDtConfirm({ value }) { dtValue.value = value }
function onRangeConfirm({ value }) { rangeValue.value = value }
function onCtrlConfirm({ value }) { ctrlValue.value = value }
</script>
```

## 注意事项

1.  **值类型与 type 对应关系**：
    -   `date` / `datetime` / `year-month` / `year`：`modelValue` 为 13 位毫秒级时间戳（`number`）
    -   `time`：`modelValue` 为时间字符串，如 `"09:30"` 或 `"09:30:00"`（开启 useSecond 时）
    -   范围模式：`modelValue` 传入数组 `[start, end]` 即自动启用范围选择，组件会显示开始/结束 Tab 切换
2.  **范围模式的边界约束**：范围模式下，开始时间不能晚于结束时间，结束时间不能早于开始时间。组件会自动禁用越界选项并在用户选择越界值时自动修正为边界值。
3.  **beforeConfirm**：支持同步返回 `boolean` 或异步返回 `Promise<boolean>`，返回 `false` 时弹窗不会关闭。注意在滚动动画进行中点击确认会被延迟到动画结束后执行。
4.  **formatter vs filter**：`formatter` 仅改变选项的显示文本，不影响可选性；`filter` 可以过滤掉特定选项使其不出现在滚轮中。两者可同时使用。
5.  **平台差异**：
    -   `immediateChange` 仅在微信小程序和支付宝小程序生效。
    -   `rootPortal` 在 H5 下使用 teleport，APP 下使用 renderjs，小程序下使用 root-portal。
6.  **defaultInnerValue**：范围模式下若 `modelValue` 为空数组，开始时间默认为 `minDate`，结束时间默认为 `maxDate`；非范围模式下若 `modelValue` 为空，滚轮初始位置取决于具体实现，建议始终传入有效初始值。
7.  **displayFormatTabLabel**：仅在范围模式下有效，用于自定义 Tab 上显示的文本格式，接收当前选中项的 label/value 数组。
8.  **与 m-calendar 的选择**：需要日历面板可视化、周/月选择、快捷选项等功能时使用 `m-calendar`；需要精确时间选择、滚轮交互、轻量级日期选择时使用 `m-datetime-picker`。
