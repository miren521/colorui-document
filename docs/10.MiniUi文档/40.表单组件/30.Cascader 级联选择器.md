# m-cascader 级联选择器

`m-cascader` 是一个级联选择组件，以弹出层形式展示多级联动选项，支持静态数据和异步加载两种模式，适用于省市区选择、分类筛选等场景。

## 基本用法

通过 `v-model` 绑定选中值，使用 `options` 传入树形选项数据。组件默认不自动弹出，需通过 `ref` 调用 `open()` 方法或设置 `visible` 属性来控制显示。

```vue
<template>
  <view>
    <m-cell title="选择地区" :value="label || '请选择'" clickable @click="cascaderRef?.open()" />
    <m-cascader
      v-model="value"
      :options="options"
      title="选择地区"
      ref="cascaderRef"
      @confirm="onConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const value = ref('')
const cascaderRef = ref()

const options = [
  {
    value: 'zhejiang',
    text: '浙江省',
    children: [
      {
        value: 'hangzhou',
        text: '杭州市',
        children: [
          { value: 'xihu', text: '西湖区' },
          { value: 'binjiang', text: '滨江区' }
        ]
      }
    ]
  }
]

function onConfirm({ value, selectedOptions }) {
  console.log('选中值:', value)
  console.log('选中路径:', selectedOptions.map(o => o.text).join(' / '))
}
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中项。静态模式下为叶子节点的值；异步模式下支持传入完整路径数组以自动逐级加载回显 | `string \| number \| (string \| number)[]` | - |
| options | 层级选项数据，树形结构 | `CascaderOption[]` | `[]` |
| title | 弹出层标题 | `string` | - |
| beforeConfirm | 确认前校验函数，返回 false 或 Promise\ 可阻止确认 | `(value, selectedOptions) => boolean \| Promise<boolean>` | - |
| checkStrictly | 是否开启任意级可选，开启后需手动点击确认按钮提交 | `boolean` | `false` |
| confirmText | 严格模式下确认按钮文案 | `string` | `''` |
| valueKey | 选项对象中值对应的字段名 | `string` | `'value'` |
| textKey | 选项对象中文本对应的字段名 | `string` | `'text'` |
| childrenKey | 选项对象中子节点对应的字段名 | `string` | `'children'` |
| tipKey | 选项对象中提示文案对应的字段名 | `string` | `'tip'` |
| isLeafKey | 选项对象中标识叶子节点的字段名，值为 true 时点击直接触发 confirm | `string` | `'isLeaf'` |
| lazyLoad | 异步加载子节点回调函数，提供后启用异步模式 | `(option, tabIndex, resolve) => void` | - |
| closeOnClickModal | 点击遮罩层是否关闭弹窗 | `boolean` | `true` |
| zIndex | 弹窗层级 | `number` | `15` |
| safeAreaInsetBottom | 是否开启底部安全区适配 | `boolean` | `true` |
| lineWidth | Tab 底部条宽度 | `number \| string` | - |
| lineHeight | Tab 底部条高度 | `number \| string` | - |
| lineTheme | Tab 底部条样式 | `'normal' \| 'text' \| 'underline' \| 'dot'` | `'normal'` |
| rootPortal | 是否从页面中脱离渲染，用于解决 fixed 定位失效问题 | `boolean` | `false` |
| visible | 控制弹窗显示/隐藏，支持 v-model:visible | `boolean` | `false` |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| confirm | 确认选择时触发 | `{ value: string \| number \| (string \| number)[], selectedOptions: CascaderOption[] }` |
| close | 弹窗关闭时触发 | - |
| update:modelValue | 双向绑定更新 | `string \| number \| (string \| number)[]` |
| update:visible | 弹窗可见性双向绑定更新 | `boolean` |

## 插槽（Slots）

源码中未定义用户可用的插槽。`checkStrictly` 模式下确认按钮区域为内部实现，非对外插槽。

## 方法（Methods）

通过 `ref` 获取组件实例后可调用以下方法：

| 方法名 | 说明 | 参数 |
| :--- | :--- | :--- |
| open | 打开级联选择器弹窗 | - |
| close | 关闭级联选择器弹窗 | - |

## 完整示例

以下示例覆盖静态数据、异步加载、任意级可选、自定义字段名等常用场景：

```vue
<template>
  <view class="demo-container">
    <!-- 基础级联选择 -->
    <m-cell title="选择地区" :value="basicLabel || '请选择'" clickable @click="basicRef?.open()" />
    <m-cascader
      v-model="basicValue"
      :options="regionOptions"
      title="选择地区"
      ref="basicRef"
      @confirm="onBasicConfirm"
    />

    <!-- 异步加载 -->
    <m-cell title="异步加载" :value="lazyLabel || '请选择'" clickable @click="lazyRef?.open()" />
    <m-cascader
      v-model="lazyValue"
      title="异步加载"
      :lazy-load="lazyLoad"
      ref="lazyRef"
      @confirm="onLazyConfirm"
    />

    <!-- 任意级可选 -->
    <m-cell title="任意级选择" :value="strictLabel || '请选择'" clickable @click="strictRef?.open()" />
    <m-cascader
      v-model="strictValue"
      :options="regionOptions"
      title="选择地区"
      check-strictly
      confirm-text="确定"
      ref="strictRef"
      @confirm="onStrictConfirm"
    />

    <!-- 自定义字段名 -->
    <m-cell title="自定义字段" :value="customLabel || '请选择'" clickable @click="customRef?.open()" />
    <m-cascader
      v-model="customValue"
      :options="customOptions"
      title="选择选项"
      value-key="id"
      text-key="name"
      children-key="items"
      ref="customRef"
      @confirm="onCustomConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import type { CascaderOption } from '@/packages/m-cascader/types'

// 基础选择
const basicValue = ref('')
const basicRef = ref()
const regionOptions: CascaderOption[] = [
  {
    value: 'zhejiang', text: '浙江省',
    children: [
      { value: 'hangzhou', text: '杭州市', children: [{ value: 'xihu', text: '西湖区' }] },
      { value: 'wuxi', text: '无锡市', children: [{ value: 'binhu', text: '滨湖区' }] }
    ]
  },
  {
    value: 'guangdong', text: '广东省',
    children: [
      { value: 'shenzhen', text: '深圳市', children: [{ value: 'nanshan', text: '南山区' }] }
    ]
  }
]
const basicLabel = computed(() => getLabelPath(regionOptions, basicValue.value))

// 异步加载
const lazyValue = ref<(string | number)[]>([])
const lazyRef = ref()
const lazyLabel = computed(() => lazyValue.value.join(' / '))

function lazyLoad(option: CascaderOption | null, tabIndex: number, resolve: (children: CascaderOption[]) => void) {
  setTimeout(() => {
    if (!option) {
      resolve([
        { value: 'level1-1', text: '一级选项A' },
        { value: 'level1-2', text: '一级选项B' }
      ])
    } else if (option.value === 'level1-1') {
      resolve([
        { value: 'level2-1', text: '二级选项A1' },
        { value: 'level2-2', text: '二级选项A2', isLeaf: true }
      ])
    } else {
      resolve([])
    }
  }, 500)
}

// 任意级可选
const strictValue = ref('')
const strictRef = ref()
const strictLabel = computed(() => getLabelPath(regionOptions, strictValue.value))

// 自定义字段
const customValue = ref('')
const customRef = ref()
const customOptions = [
  { id: '1', name: '选项一', items: [{ id: '1-1', name: '子选项一' }] },
  { id: '2', name: '选项二', items: [{ id: '2-1', name: '子选项二' }] }
]
const customLabel = computed(() => getLabelPath(customOptions, customValue.value, 'id', 'name', 'items'))

function getLabelPath(options: any[], value: string | number, vk = 'value', tk = 'text', ck = 'children'): string {
  if (!value) return ''
  function find(opts: any[], target: string | number, path: string[]): string[] | null {
    for (const item of opts) {
      if (item[vk] === target) return [...path, item[tk]]
      if (item[ck]?.length) {
        const r = find(item[ck], target, [...path, item[tk]])
        if (r) return r
      }
    }
    return null
  }
  return find(options, value, [])?.join(' / ') || ''
}

function onBasicConfirm({ selectedOptions }) { uni.showToast({ title: selectedOptions.map(o => o.text).join(' / '), icon: 'none' }) }
function onLazyConfirm({ selectedOptions }) { uni.showToast({ title: selectedOptions.map(o => o.text).join(' / '), icon: 'none' }) }
function onStrictConfirm({ selectedOptions }) { uni.showToast({ title: selectedOptions.map(o => o.text).join(' / '), icon: 'none' }) }
function onCustomConfirm({ selectedOptions }) { uni.showToast({ title: selectedOptions.map(o => o.name).join(' / '), icon: 'none' }) }
</script>
```

## 注意事项

1.  **静态与异步模式的值类型差异**：静态模式下 `modelValue` 为叶子节点的单个值（`string | number`），confirm 事件也返回单个值；异步模式下 `modelValue` 支持传入完整路径数组 `(string | number)[]`，组件会自动逐级加载并回显，confirm 事件返回的也是路径数组。
2.  **lazyLoad 回调**：第一个参数 `option` 为 `null` 时表示加载根节点；调用 `resolve([])` 传入空数组表示该节点为叶子节点，将自动触发 confirm。务必在异步操作完成后调用 `resolve`，否则面板会一直处于 loading 状态。
3.  **isLeaf 标记**：在异步模式下，若某节点没有子节点但也不是最终叶子节点，可通过设置 `isLeaf: true`（或通过 `isLeafKey` 自定义字段名）来标识该节点点击后直接触发 confirm，不再调用 `lazyLoad`。
4.  **checkStrictly 模式**：开启后点击节点仅更新当前路径选中状态，不会自动触发 confirm，需用户手动点击右上角确认按钮。再次点击已选中节点可取消选中。
5.  **beforeConfirm**：支持同步返回 `boolean` 或异步返回 `Promise<boolean>`，返回 `false` 时弹窗不会关闭，可用于表单校验等场景。
6.  **平台差异**：
    -   `rootPortal` 在 H5 下使用 teleport，APP 下使用 renderjs，小程序下使用 root-portal 组件。头条小程序不支持 `virtualHost`，源码中已做条件编译排除。
7.  **options 更新**：静态模式下修改 `options` 会自动重建面板；异步模式下仅在已有缓存数据时重建，否则依赖 `lazyLoad` 重新加载。
8.  **disabled 选项**：选项对象中设置 `disabled: true` 可禁用该选项，点击无效。
