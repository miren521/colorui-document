# m-calendar 日历选择器

`m-calendar` 是一个功能丰富的日历选择组件，支持单日、多日、日期范围、时间、周、月等多种选择模式，以弹出层形式展示，适用于各类日期和时间选择场景。

## 基本用法

通过 `v-model` 绑定选中值（13位时间戳），使用 `type` 指定选择类型。组件默认不自动弹出，需通过 `ref` 调用 `open()` 方法或设置 `visible` 属性来控制显示。

```vue
<template>
  <view>
    <button @click="calendarRef?.open()">选择日期</button>
    <m-calendar
      v-model="dateValue"
      type="date"
      title="选择日期"
      ref="calendarRef"
      @confirm="onConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const dateValue = ref<number | null>(null)
const calendarRef = ref()

function onConfirm({ value }) {
  console.log('选中日期:', new Date(value))
}
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| modelValue | 选中值，为 13 位时间戳或时间戳数组 | `number \| number[] \| null` | - (必填) |
| type | 日期选择类型 | `'date' \| 'dates' \| 'datetime' \| 'week' \| 'month' \| 'daterange' \| 'datetimerange' \| 'weekrange' \| 'monthrange'` | `'date'` |
| minDate | 最小可选日期，13 位时间戳 | `number` | 当前日期前一年同日 |
| maxDate | 最大可选日期，13 位时间戳 | `number` | 当前日期后一年同日 |
| firstDayOfWeek | 周起始天，0 表示周日 | `number` | `0` |
| formatter | 日期格式化函数，自定义日期单元格显示 | `CalendarFormatter` | - |
| maxRange | 范围选择时的最大跨度天数 | `number` | - |
| rangePrompt | 超出最大范围时的提示文案 | `string` | - |
| allowSameDay | 范围选择时是否允许起止为同一天 | `boolean` | `false` |
| defaultTime | 选中日期所使用的当日内具体时刻 | `string \| string[]` | - |
| timeFilter | 时间选择器数据过滤函数，仅 datetime/datetimerange 有效 | `CalendarTimeFilter` | - |
| hideSecond | 是否隐藏秒选择，仅 datetime/datetimerange 有效 | `boolean` | `false` |
| title | 弹出层标题 | `string` | - |
| closeOnClickModal | 点击遮罩层是否关闭弹窗 | `boolean` | `true` |
| zIndex | 弹框层级 | `number` | `15` |
| showConfirm | 是否显示确定按钮 | `boolean` | `true` |
| confirmText | 确定按钮文字 | `string` | - |
| innerDisplayFormat | 自定义范围选择面板内部的回显格式函数 | `(value: number, rangeType: 'start' \| 'end', type: CalendarType) => string` | - |
| ellipsis | 是否超出隐藏 | `boolean` | `false` |
| showTypeSwitch | 是否显示日/周/月类型切换 Tab | `boolean` | `false` |
| shortcuts | 快捷选项数组，每项需包含 text 字段 | `Record<string, any>[]` | `[]` |
| onShortcutsClick | 快捷选项点击回调，返回时间戳或时间戳数组 | `(option: { item, index }) => number \| number[]` | - |
| safeAreaInsetBottom | 是否开启底部安全区适配 | `boolean` | `true` |
| immediateChange | 手指松开时立即触发 change，仅微信/支付宝小程序支持 | `boolean` | `false` |
| rootPortal | 是否从页面中脱离渲染，用于解决 fixed 定位失效问题 | `boolean` | `false` |
| visible | 控制弹窗显示/隐藏，支持 .sync / v-model:visible | `boolean` | `false` |
| panelHeight | 可滚动面板高度（px） | `number` | `316` |
| showPanelTitle | 是否展示面板顶部月份标题 | `boolean` | `true` |
| switchMode | 月份/年份切换模式 | `'none' \| 'month' \| 'year-month'` | `'none'` |
| duration | 弹框动画持续时间（ms） | `number` | `200` |
| customClass | 自定义根节点类名 | `string` | - |
| customStyle | 自定义根节点样式 | `string` | - |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| confirm | 确认选择时触发 | `{ value: number \| number[], type: CalendarType }` |
| change | 选中值变化时触发 | `{ value: number \| number[] \| null }` |
| cancel | 关闭弹窗且未确认时触发 | - |
| open | 弹窗打开时触发 | - |
| update:modelValue | 双向绑定更新 | `number \| number[] \| null` |
| update:visible | 弹窗可见性双向绑定更新 | `boolean` |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |

## 完整示例

以下示例覆盖常用选择模式及配置项：

```vue
<template>
  <view class="demo-container">
    <!-- 基础日期选择 -->
    <m-cell title="选择日期" :value="dateLabel || '请选择'" clickable @click="dateRef?.open()" />
    <m-calendar
      v-model="dateValue"
      type="date"
      title="选择日期"
      ref="dateRef"
      @confirm="onDateConfirm"
    />

    <!-- 日期范围选择 + 最大跨度限制 -->
    <m-cell title="日期范围" :value="rangeLabel || '请选择'" clickable @click="rangeRef?.open()" />
    <m-calendar
      v-model="rangeValue"
      type="daterange"
      title="选择日期范围"
      :max-range="7"
      range-prompt="最多选择7天"
      allow-same-day
      ref="rangeRef"
      @confirm="onRangeConfirm"
    />

    <!-- 日期时间选择 -->
    <m-cell title="日期时间" :value="datetimeLabel || '请选择'" clickable @click="datetimeRef?.open()" />
    <m-calendar
      v-model="datetimeValue"
      type="datetime"
      title="选择日期时间"
      hide-second
      ref="datetimeRef"
      @confirm="onDatetimeConfirm"
    />

    <!-- 自定义格式化 + 自定义按钮文本 -->
    <m-cell title="格式化日期" :value="formatterLabel || '请选择'" clickable @click="formatterRef?.open()" />
    <m-calendar
      v-model="formatterValue"
      type="date"
      title="自定义格式化"
      :formatter="customFormatter"
      confirm-text="好的"
      ref="formatterRef"
      @confirm="onFormatterConfirm"
    />

    <!-- 通过 visible 控制弹窗 -->
    <m-cell title="受控弹窗" :value="controlledLabel || '请选择'" clickable @click="controlledVisible = true" />
    <m-calendar
      v-model="controlledValue"
      type="date"
      v-model:visible="controlledVisible"
      title="受控弹窗"
      @confirm="onControlledConfirm"
    />
  </view>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import type { CalendarDayItem } from '@/packages/m-calendar-view/types'

const now = new Date()
const today = now.getTime()

// 基础日期
const dateValue = ref<number | null>(today)
const dateRef = ref()
const dateLabel = computed(() => dateValue.value ? formatDate(dateValue.value) : '')

// 日期范围
const rangeValue = ref<(number | null)[]>([])
const rangeRef = ref()
const rangeLabel = computed(() => {
  if (!rangeValue.value?.[0] || !rangeValue.value?.[1]) return ''
  return `${formatDate(rangeValue.value[0])} - ${formatDate(rangeValue.value[1])}`
})

// 日期时间
const datetimeValue = ref<number | null>(null)
const datetimeRef = ref()
const datetimeLabel = computed(() => datetimeValue.value ? formatDatetime(datetimeValue.value) : '')

// 自定义格式化
const formatterValue = ref<number | null>(null)
const formatterRef = ref()
const formatterLabel = computed(() => formatterValue.value ? formatDate(formatterValue.value) : '')

// 受控弹窗
const controlledValue = ref<number | null>(null)
const controlledVisible = ref(false)
const controlledLabel = computed(() => controlledValue.value ? formatDate(controlledValue.value) : '')

function formatDate(ts: number) {
  const d = new Date(ts)
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`
}

function formatDatetime(ts: number) {
  const d = new Date(ts)
  return `${formatDate(ts)} ${String(d.getHours()).padStart(2, '0')}:${String(d.getMinutes()).padStart(2, '0')}`
}

function customFormatter(day: CalendarDayItem): CalendarDayItem {
  const date = new Date(day.date)
  const dow = date.getDay()
  if (dow === 0 || dow === 6) {
    day.bottomInfo = '周末'
    day.customClass = 'is-weekend'
  }
  const today = new Date()
  if (date.getDate() === today.getDate() && date.getMonth() === today.getMonth() && date.getFullYear() === today.getFullYear()) {
    day.topInfo = '今天'
  }
  return day
}

function onDateConfirm({ value }) { uni.showToast({ title: formatDate(value), icon: 'none' }) }
function onRangeConfirm({ value }) { uni.showToast({ title: `${formatDate(value[0])} - ${formatDate(value[1])}`, icon: 'none' }) }
function onDatetimeConfirm({ value }) { uni.showToast({ title: formatDatetime(value), icon: 'none' }) }
function onFormatterConfirm({ value }) { uni.showToast({ title: formatDate(value), icon: 'none' }) }
function onControlledConfirm({ value }) { uni.showToast({ title: formatDate(value), icon: 'none' }) }
</script>
```

## 注意事项

1.  **值类型**：`modelValue` 必须为 13 位毫秒级时间戳（`number`），范围类型为 `[number, number]` 数组，多日期为 `number[]`。传入非时间戳值可能导致异常。
2.  **弹窗控制**：组件默认不自动弹出。推荐使用 `ref.open()` 手动打开，或通过 `v-model:visible` 双向绑定控制。两种方式不要混用。
3.  **平台差异**：
    -   `immediateChange` 属性仅在微信小程序和支付宝小程序生效，H5 和其他平台不支持。
    -   `rootPortal` 在 H5 下使用 teleport，APP 下使用 renderjs，小程序下使用 root-portal 组件。头条小程序不支持 `virtualHost`，源码中已做条件编译排除。
4.  **showTypeSwitch**：开启后仅支持在 `date/week/month` 或 `daterange/weekrange/monthrange` 同组内切换，不支持跨组切换（如从 date 切换到 daterange）。
5.  **shortcuts**：快捷选项必须配合 `onShortcutsClick` 回调使用，回调需返回合法的时间戳或时间戳数组，否则选中值不会更新。
6.  **showConfirm 为 false 时**：用户选择完成后会自动触发 confirm，无需手动点击确认按钮；范围选择时需选满起止两端才会自动确认。
7.  **formatter 函数**：接收 `CalendarDayItem` 对象并返回修改后的同一对象，不要返回新对象，否则可能导致状态丢失。
8.  **defaultTime**：仅在未选择具体时间时作为默认时刻填充，格式为 `"HH:mm:ss"` 字符串，范围类型可传数组分别指定起止时间。
