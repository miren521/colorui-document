# m-transition 过渡动画

通用 CSS 过渡动画容器，通过 `show` 属性驱动元素的进入/离开动画。内置 10 种预设动画，支持自定义动画类名、独立控制进出时长及懒渲染优化。基于 `AbortablePromise` 实现动画中断安全，避免快速切换状态时的动画错乱。

## 基本用法

```vue
<template>
  <m-button @click="visible = !visible">切换</m-button>
  <m-transition :show="visible" name="fade">
    <view class="content">Hello Transition</view>
  </m-transition>
</template>

<script setup lang="ts">
import { ref } from 'vue'
const visible = ref(false)
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| show | 是否显示内容并触发动画 | boolean | `false` |
| name | 预设动画名称，支持单个或数组组合 | `TransitionName \| TransitionName[]` | `'fade'` |
| duration | 动画时长（ms），支持对象分别设置 enter/leave | number \| `{ enter: number, leave: number }` | `300` |
| lazy-render | 懒渲染：首次 `show=true` 前不渲染插槽内容 | boolean | `false` |
| destroy | 离开动画结束后是否隐藏元素（display:none） | boolean | `true` |
| disable-touch-move | 动画期间是否阻止触摸滚动穿透 | boolean | `false` |
| enter-class | 自定义进入过渡起始类名 | string | `''` |
| enter-active-class | 自定义进入过渡激活类名 | string | `''` |
| enter-to-class | 自定义进入过渡结束类名 | string | `''` |
| leave-class | 自定义离开过渡起始类名 | string | `''` |
| leave-active-class | 自定义离开过渡激活类名 | string | `''` |
| leave-to-class | 自定义离开过渡结束类名 | string | `''` |
| custom-class | 自定义根节点类名 | string | `''` |
| custom-style | 自定义根节点样式 | string | `''` |

### 预设动画名称（TransitionName）

| 名称 | 效果 |
| :--- | :--- |
| fade | 淡入淡出 |
| fade-up / fade-down / fade-left / fade-right | 带方向的淡入淡出 |
| slide-up / slide-down / slide-left / slide-right | 纯位移滑动（无透明度变化） |
| zoom-in / zoom-out | 缩放进入/退出 |

## 事件（Events）

| 事件名 | 说明 |
| :--- | :--- |
| before-enter | 进入动画开始前触发 |
| enter | 进入动画激活时触发 |
| after-enter | 进入动画完成后触发 |
| before-leave | 离开动画开始前触发 |
| leave | 离开动画激活时触发 |
| after-leave | 离开动画完成后触发 |
| click | 点击内容区域时触发 |

## 完整示例

### 组合动画
```vue
<!-- 同时应用 fade + slide-up -->
<m-transition :show="visible" :name="['fade', 'slide-up']">
  <view>组合效果</view>
</m-transition>
```

### 独立进出时长
```vue
<m-transition 
  :show="visible" 
  name="zoom-in"
  :duration="{ enter: 600, leave: 200 }"
>
  <view>慢进快出</view>
</m-transition>
```

### 完全自定义动画类名
```vue
<m-transition
  :show="visible"
  enter-class="my-enter"
  enter-active-class="my-enter-active"
  enter-to-class="my-enter-to"
  leave-class="my-leave"
  leave-active-class="my-leave-active"
  leave-to-class="my-leave-to"
>
  <view>自定义旋转缩放</view>
</m-transition>

<style scoped>
.my-enter-active, .my-leave-active { transition: all 0.6s ease; }
.my-enter { transform: scale(0) rotate(0deg); opacity: 0; }
.my-enter-to { transform: scale(1) rotate(360deg); opacity: 1; }
.my-leave { transform: scale(1) rotate(360deg); opacity: 1; }
.my-leave-to { transform: scale(0) rotate(720deg); opacity: 0; }
</style>
```

### 懒渲染优化
```vue
<!-- 列表项等场景，未展示时不渲染 DOM -->
<m-transition :show="item.visible" name="fade" lazy-render>
  <heavy-component />
</m-transition>
```

### 防止滚动穿透
```vue
<!-- 全屏弹窗等场景，阻止背景滚动 -->
<m-transition :show="popupVisible" name="fade-up" disable-touch-move>
  <view class="fullscreen-modal">...</view>
</m-transition>
```

## 注意事项

1.  **动画中断安全**：内部使用 `AbortablePromise` 管理动画生命周期。快速连续切换 `show` 时，前一个未完成的动画会被自动中止，不会出现动画叠加或状态错乱。
2.  **destroy vs display**：`destroy=true`（默认）时，离开动画结束后元素设为 `display: none`，仍保留在 DOM 中；若需完全移除 DOM，请配合 `v-if` 使用。`destroy=false` 时元素始终可见（仅靠动画类控制显隐），适用于需要保持布局占位的场景。
3.  **lazy-render 时机**：仅在首次 `show` 从 `false` 变为 `true` 时触发渲染。之后即使 `show` 再次为 `false`，已渲染的内容不会销毁（由 `destroy` 控制）。适合重型组件延迟初始化。
4.  **duration 类型兼容**：传入 `boolean` 类型时，`true` 等同于默认 300ms，`false` 等同于 0ms（无动画）。建议始终使用 number 或对象形式以保持语义清晰。
5.  **自定义类名与预设叠加**：当同时设置 `name` 和自定义 `enterClass` 等属性时，两者会**合并**而非替换。自定义类名追加在预设类名之后，可用于微调预设动画。
6.  **transitionend 依赖**：动画完成检测依赖原生 `transitionend` 事件。若 CSS 中未定义 `transition` 属性或属性名不匹配，`after-enter/after-leave` 可能不触发。离开动画额外设置了定时器兜底，确保 `onTransitionEnd` 一定执行。
7.  **disable-touch-move 实现**：通过在动画期间绑定 `@touchmove.stop.prevent` 空函数实现。仅在 `show=true` 且该属性为 `true` 时生效。注意这会阻止内容区自身的滚动，长内容弹窗请勿开启。
8.  **虚拟宿主**：启用 `virtualHost: true`，`custom-class/style` 直接作用于过渡容器的根 `<view>`。在小程序中不会产生额外包裹层，但需确保插槽内容有明确的尺寸定义，否则过渡动画可能无效。
9.  **name 数组顺序**：多动画组合时，类名按数组顺序依次拼接。CSS 优先级遵循后写覆盖原则，若多个预设动画修改同一属性，后面的会生效。建议组合正交属性（如 fade + slide）。
10. **性能优化提示**：自定义动画中建议添加 `transform: translateZ(0)` 或 `will-change` 触发 GPU 加速，减少小程序模拟器及低端设备的闪烁。避免对 `width/height/margin` 等触发重排的属性做过渡。
