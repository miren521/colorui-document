# m-notice-bar 通知栏

用于展示系统公告、消息提醒等滚动或静态通知内容，支持水平/垂直滚动、多种类型主题、可关闭、自定义图标与颜色，以及插槽扩展。

## 基本用法

```vue
<template>
  <m-notice-bar text="这是一条普通的通知消息" />
</template>

<script setup lang="ts">
import mNoticeBar from '@/packages/m-notice-bar/m-notice-bar.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| text | 通知内容，字符串为单条通知，数组为多条轮播通知 | string \| string[] | `''` |
| type | 通知类型，影响左侧默认图标和背景色 | `'warning' \| 'info' \| 'danger' \| ''` | `'warning'` |
| scrollable | 是否开启滚动，`false` 时超出内容显示省略号 | boolean | `true` |
| wrapable | 是否允许换行显示（仅水平方向且 `scrollable=false` 时生效） | boolean | `false` |
| direction | 滚动方向 | `'horizontal' \| 'vertical'` | `'horizontal'` |
| speed | 滚动速度，单位 px/s | number | `50` |
| delay | 首次滚动前的延迟时间，单位秒 | number | `1` |
| closable | 是否显示右侧关闭按钮 | boolean | `false` |
| prefix | 左侧自定义图标名称（对应 `m-icon` 的 name），设置后覆盖 `type` 默认图标 | string | 源码中未明确说明 |
| color | 自定义文字颜色 | string | 源码中未明确说明 |
| backgroundColor | 自定义背景颜色 | string | 源码中未明确说明 |
| custom-class | 自定义外层容器类名 | string | `''` |
| custom-style | 自定义外层容器样式 | string | `''` |

### type 默认图标映射

| type | 默认图标 |
| :--- | :--- |
| warning | exclamation-circle-fill |
| info | info-circle-fill |
| danger | close-circle-fill |
| '' (空) | 无图标 |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| click | 点击通知内容区域时触发 | `{ index: number, text: string }` |
| close | 点击关闭按钮时触发 | - |
| next | 垂直轮播切换到下一条时触发 | index: number（当前索引） |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| prefix | 自定义左侧图标区域，传入后 `prefix` 属性和 `type` 默认图标均不渲染 |
| suffix | 自定义右侧区域，传入后 `closable` 关闭按钮不渲染 |
| default | 水平模式下自定义通知文本内容（替代 `text` 属性的文本渲染）；垂直模式下此插槽无效 |

## 方法（Methods）

通过组件 ref 调用：

| 方法名 | 说明 |
| :--- | :--- |
| reset() | 重置并重新开始滚动动画 |

```vue
<m-notice-bar ref="noticeBarRef" text="通知内容" />

<script setup lang="ts">
import { ref } from 'vue'
import type { NoticeBarInstance } from '@/packages/m-notice-bar/types'

const noticeBarRef = ref<NoticeBarInstance>()
function restart() { noticeBarRef.value?.reset() }
</script>
```

## 完整示例

```vue
<template>
  <!-- 基础用法 -->
  <m-notice-bar text="这是一条普通的通知消息" />

  <!-- 不同类型 -->
  <m-notice-bar text="警告通知" type="warning" />
  <m-notice-bar text="信息通知" type="info" />
  <m-notice-bar text="危险通知" type="danger" />

  <!-- 可关闭 -->
  <m-notice-bar text="点击右侧按钮可关闭" closable @close="onClose" />

  <!-- 自定义图标 -->
  <m-notice-bar text="有新消息提醒" prefix="sound-fill" />

  <!-- 自定义颜色 -->
  <m-notice-bar text="自定义颜色通知" color="#59CDAA" background-color="#F3FBF9" />

  <!-- 不滚动 + 省略号 -->
  <m-notice-bar text="很长的不滚动通知内容超出省略..." :scrollable="false" />

  <!-- 换行显示 -->
  <m-notice-bar text="支持换行的较长通知内容..." :wrapable="true" :scrollable="false" />

  <!-- 纵向滚动 -->
  <m-notice-bar :text="['第一条', '第二条', '第三条']" direction="vertical" />

  <!-- 自定义速度与延迟 -->
  <m-notice-bar text="慢速滚动" :speed="20" />
  <m-notice-bar text="延迟3秒开始" :delay="3" />

  <!-- 插槽自定义 -->
  <m-notice-bar>
    <template #prefix>
      <m-icon name="gift" style="font-size: 18px; color: #ff6b6b;" />
    </template>
    <text>限时优惠：全场商品8折起</text>
    <template #suffix>
      <m-button type="warning" size="small">立即抢购</m-button>
    </template>
  </m-notice-bar>
</template>

<script setup lang="ts">
import mNoticeBar from '@/packages/m-notice-bar/m-notice-bar.vue'

function onClose() {
  console.log('通知已关闭')
}
</script>
```

## 注意事项

1.  **text 类型决定行为**：传入字符串时为单条通知（水平滚动或静态展示）；传入数组时自动进入轮播模式，水平方向逐条切换，垂直方向上下滚动轮播。
2.  **scrollable 与 wrapable 互斥**：`wrapable=true` 仅在 `scrollable=false` 且 `direction='horizontal'` 时生效；开启滚动时换行设置被忽略。
3.  **垂直滚动条件**：`direction='vertical'` 时，仅当 `text` 为数组且长度 > 1 时才启动滚动动画；单条文本垂直模式下不滚动。
4.  **speed 单位**：`speed` 单位为 **px/s**，数值越大滚动越快。实际动画时长由内容宽度（或高度）除以 speed 动态计算。
5.  **页面生命周期联动**：组件在 `onShow` 时恢复动画、`onHide` 时暂停动画；APP-PLUS 平台额外监听 webview 的 show/hide 事件。若手动调用 `reset()`，会重置所有动画状态并重新开始。
6.  **prefix 插槽优先级**：传入 `#prefix` 插槽后，`prefix` 属性和 `type` 对应的默认图标均不渲染；同理，传入 `#suffix` 插槽后 `closable` 关闭按钮不渲染。
7.  **click 事件参数**：数组模式下返回当前显示的条目索引和文本；字符串模式下 index 固定为 0。
8.  **动画依赖 DOM 测量**：滚动动画通过 `getRect` 异步获取容器和内容尺寸后启动，若组件处于隐藏状态（如 `v-if=false` 或页面不可见）时挂载，可能因尺寸为 0 导致动画不启动，需在可见后手动调用 `reset()`。
9.  **平台差异**：组件 options 中使用了 `virtualHost: true`，该选项在头条小程序（MP-TOUTIAO）下被条件编译排除；其他平台虚拟宿主节点生效。
10. **外部样式依赖**：通知栏的主题色、省略号、换行、滚动容器等样式均由 `./index.scss` 定义，自定义主题时需确保该文件正确引入。
