# m-loading 加载

用于展示加载中状态的组件，提供多种动画类型、自定义颜色与尺寸、加载文本及排列方向，适用于按钮加载、列表加载、全屏加载等场景。

## 基本用法

```vue
<template>
  <m-loading />
  <m-loading type="spinner" />
  <m-loading type="circular" text="加载中..." />
</template>

<script setup lang="ts">
import mLoading from '@/packages/m-loading/m-loading.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| type | 加载动画类型 | `'circular' \| 'spinner' \| 'dots' \| 'wave' \| 'pulse' \| 'sync'` | `'circular'` |
| color | 加载动画颜色 | string | 源码中未明确说明 |
| size | 加载动画尺寸，支持数字（默认单位 px）或带单位的字符串 | string \| number | 源码中未明确说明 |
| text | 加载提示文字 | string | 源码中未明确说明 |
| direction | 图标与文字的排列方向 | `'vertical' \| 'horizontal'` | `'vertical'` |
| inherit-color | 是否继承父元素的 `color` 值作为加载颜色 | boolean | `false` |
| custom-class | 自定义外层容器类名 | string | `''` |
| custom-style | 自定义外层容器样式 | string | `''` |
| custom-spinner-class | 自定义加载图标区域类名 | string | `''` |

### type 可选值说明

| 值 | 动画效果 |
| :--- | :--- |
| circular | 环形旋转加载 |
| spinner | 12 个点依次旋转 |
| dots | 3 个点闪烁 |
| wave | 4 根柱状条波浪起伏 |
| pulse | 双点脉冲缩放 |
| sync | 双点左右交替出现 |

## 事件（Events）

源码中未定义任何事件。

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 自定义加载文本内容，传入后 `text` 属性不再生效；不传且 `text` 有值时显示 `text` 文本 |

## 方法（Methods）

源码中未通过 ref 暴露任何方法。

## 完整示例

```vue
<template>
  <!-- 各类型加载 -->
  <view class="row">
    <m-loading type="circular" />
    <m-loading type="spinner" />
    <m-loading type="dots" />
    <m-loading type="wave" />
    <m-loading type="pulse" />
    <m-loading type="sync" />
  </view>

  <!-- 自定义颜色 -->
  <m-loading type="circular" color="#ff6b6b" />

  <!-- 自定义尺寸 -->
  <m-loading type="circular" :size="40" />

  <!-- 加载文本 -->
  <m-loading type="circular" text="加载中..." />

  <!-- 水平排列 -->
  <m-loading type="wave" direction="horizontal" text="加载中..." />

  <!-- 继承父元素颜色 -->
  <view style="color: #ff6b6b;">
    <m-loading type="circular" inherit-color />
  </view>

  <!-- 插槽自定义文本 -->
  <m-loading type="circular">
    <text class="custom-text">正在提交订单...</text>
  </m-loading>
</template>

<script setup lang="ts">
import mLoading from '@/packages/m-loading/m-loading.vue'
</script>

<style scoped lang="scss">
.row {
  display: flex;
  gap: 20px;
  align-items: center;
  margin-bottom: 16px;
}
.custom-text {
  font-size: 14px;
  color: #666;
}
</style>
```

## 注意事项

1.  **color 与 inherit-color 优先级**：同时设置 `color` 和 `inherit-color` 时，`inherit-color` 优先生效（源码中 `inheritColor` 判断在 `color` 之后，会覆盖 `color` 设置的值）。若需使用自定义颜色，请勿同时开启 `inherit-color`。
2.  **size 单位处理**：传入纯数字时自动追加 `px` 单位；传入字符串时需自带单位（如 `'2rem'`、`'80rpx'`）。`size` 同时设置 spinner 区域的 `width` 和 `height`，确保各类型动画等比缩放。
3.  **文本显示条件**：仅当传入默认插槽 **或** `text` 属性有值时，才渲染文本节点；两者都为空时不渲染文本区域，避免多余间距。
4.  **插槽优先于 text**：传入默认插槽后，`text` 属性被忽略，仅渲染插槽内容。
5.  **direction 布局**：`vertical` 为图标在上、文字在下（纵向排列）；`horizontal` 为图标在左、文字在右（横向排列）。具体间距和对齐方式由外部 SCSS 定义。
6.  **动画依赖外部样式**：所有 6 种类型的动画实现均在 `./index.scss` 中定义，组件模板仅提供结构节点。若自定义主题或单独引入组件，务必确保该样式文件已正确加载，否则仅显示静态结构无动画效果。
7.  **virtualHost**：组件 options 中启用了 `virtualHost: true`，外层不生成额外 DOM 节点，`custom-class` 和 `custom-style` 直接作用于内部根 `<view>`。在部分小程序平台中若遇到样式穿透问题，可检查该选项的平台兼容性。
8.  **spinner 点数固定**：`spinner` 类型固定渲染 12 个点，`dots` 类型固定 3 个点，`wave` 类型固定 4 根柱条，`pulse` 和 `sync` 类型固定 2 个点，均不支持通过 props 自定义数量。
