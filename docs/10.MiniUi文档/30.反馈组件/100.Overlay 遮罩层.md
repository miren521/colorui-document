# m-overlay 遮罩层

用于创建一个覆盖全屏的半透明遮罩，通常作为弹窗、抽屉等组件的背景层。基于 `m-transition` 实现淡入淡出动画，支持自定义层级、动画时长及滚动锁定控制。

## 基本用法

```vue
<template>
  <m-button @click="visible = true">显示遮罩</m-button>
  
  <m-overlay :show="visible" @click="visible = false">
    <!-- 遮罩上方的内容（如弹窗） -->
    <view class="content">点击遮罩关闭</view>
  </m-overlay>
</template>

<script setup lang="ts">
import { ref } from 'vue'
const visible = ref(false)
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| show | 是否显示遮罩层 | boolean | `false` |
| z-index | 遮罩层层级 | number | `10` |
| duration | 动画时长（ms），支持对象形式分别设置进入/离开时长 | number \| Record \| boolean | `300` |
| lock-scroll | 是否锁定背景滚动，防止穿透 | boolean | `true` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式（常用于修改背景色） | string | `''` |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| click | 点击遮罩层时触发 | - |
| before-enter | 进入动画开始前触发 | - |
| enter | 进入动画进行中触发 | - |
| after-enter | 进入动画完成后触发 | - |
| before-leave | 离开动画开始前触发 | - |
| leave | 离开动画进行中触发 | - |
| after-leave | 离开动画完成后触发 | - |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 遮罩层上方显示的内容（如弹窗主体）。注意：插槽内容会随遮罩层一同进行 fade 动画 |

## 完整示例

### 自定义背景色与层级
```vue
<m-overlay 
  :show="visible" 
  :z-index="100" 
  custom-style="background: rgba(255, 0, 0, 0.3);" 
  @click="visible = false"
/>
```

### 监听过渡生命周期
```vue
<m-overlay 
  :show="visible" 
  @after-enter="onOpened" 
  @after-leave="onClosed"
>
  <view class="popup">内容</view>
</m-overlay>
```

### 不锁定滚动
适用于需要在遮罩显示时仍能滑动底层页面的场景（如悬浮球、侧边导航）：
```vue
<m-overlay :show="visible" :lock-scroll="false" />
```

## 注意事项

1.  **定位方式**：`m-overlay` 本身仅提供全屏覆盖和动画能力，**不包含内容居中逻辑**。若需在遮罩上展示居中弹窗，请在插槽内容中自行使用 `position: fixed` + `transform` 或 Flex 布局定位。
2.  **插槽动画联动**：默认插槽内的元素会跟随遮罩层一起执行 `fade` 动画。如果希望内容以其他动画（如缩放、滑入）出现，建议将内容抽离为独立组件并配合 `m-transition` 单独控制，或将 `m-overlay` 仅作为纯背景层使用。
3.  **duration 类型**：
    -   `number`: 统一设置进入和离开时长。
    -   `Record<string, number>`: 可分别指定 `{ enter: 300, leave: 200 }`。
    -   `boolean`: `false` 表示禁用动画，立即切换显隐状态。
4.  **滚动锁定机制**：`lock-scroll=true` 时，组件内部通过 `disable-touch-move` 阻止触摸移动事件。在部分小程序平台可能存在穿透问题，建议结合页面级滚动控制做兜底处理。
5.  **z-index 管理**：默认层级为 10。当与 `m-popup`、`m-dialog` 等组件混用时，请注意层级冲突。这些组件通常有更高的默认 z-index，确保遮罩层不会意外覆盖弹窗内容。
6.  **点击关闭**：点击遮罩任意区域（包括插槽内容外的空白处）均会触发 `click` 事件。若需区分“点击遮罩背景”和“点击内容”，请在插槽根元素上添加 `@click.stop` 阻止冒泡。
7.  **虚拟宿主**：组件启用了 `virtualHost: true`（头条小程序除外），不会生成额外的 DOM 包裹节点，`custom-class` 和 `custom-style` 直接作用于内部 `m-transition` 根节点。
8.  **样式隔离**：`styleIsolation: 'shared'` 允许外部样式穿透。如需修改遮罩背景色以外的样式（如圆角、模糊效果），可通过 `custom-style` 或全局覆盖 `.m-overlay` 类实现。
9.  **性能优化**：`show=false` 且动画结束后，内容虽不可见但仍存在于 DOM 中（由 `m-transition` 决定）。若遮罩内容较重且频繁切换，建议在外层额外包裹 `v-if` 以彻底销毁重建。
10. **平台差异**：头条小程序不支持 `virtualHost`，组件会生成真实节点。在该平台下若遇到样式异常，请检查父容器布局对额外节点的影响。
