# m-empty 空状态

用于在列表、搜索结果、购物车等无数据场景下展示缺省提示的组件，支持自定义图标、提示文案及底部操作区域。

## 基本用法

```vue
<template>
  <m-empty />
  <m-empty tip="暂无数据" />
</template>

<script setup lang="ts">
import mEmpty from '@/packages/m-empty/m-empty.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| icon | 图标名称（对应 `m-icon` 的 name）或图片 URL | string | `'empty'` |
| icon-size | 图标尺寸，支持数字（默认单位 px）或带单位的字符串 | string \| number | 源码中未明确说明 |
| tip | 提示文案，为空时不渲染文本节点 | string | `''` |
| custom-class | 自定义外层容器类名 | string | `''` |
| custom-style | 自定义外层容器样式 | string | `''` |

## 事件（Events）

源码中未定义任何事件。

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| image | 自定义图标/图片区域，传入后内置 `m-icon` 不再渲染 |
| bottom | 底部自定义内容，通常用于放置操作按钮 |

## 方法（Methods）

源码中未通过 ref 暴露任何方法。

## 完整示例

```vue
<template>
  <!-- 基础用法 -->
  <m-empty />

  <!-- 自定义提示文案 -->
  <m-empty tip="暂无数据" />

  <!-- 自定义图标 -->
  <m-empty icon="shake" tip="未搜索到相关内容" />

  <!-- 自定义图标大小 -->
  <m-empty icon="printer" :icon-size="120" tip="购物车空空如也" />

  <!-- 自定义图片插槽 -->
  <m-empty tip="暂无收藏">
    <template #image>
      <view class="custom-icon">
        <text class="icon-text">♥</text>
      </view>
    </template>
  </m-empty>

  <!-- 底部插槽：添加操作按钮 -->
  <m-empty tip="暂无优惠券">
    <template #bottom>
      <m-button type="primary" size="small" style="margin-top: 10px;">去领取</m-button>
    </template>
  </m-empty>

  <!-- 完整组合示例 -->
  <m-empty icon="mind-mapping" :icon-size="160" tip="暂无收货地址">
    <template #bottom>
      <m-button type="primary" size="small" style="margin-top: 10px;">添加收货地址</m-button>
    </template>
  </m-empty>
</template>

<script setup lang="ts">
import mEmpty from '@/packages/m-empty/m-empty.vue'
</script>

<style scoped lang="scss">
.custom-icon {
  width: 98px;
  height: 98px;
  display: flex;
  align-items: center;
  justify-content: center;
  background-color: #fef2f2;
  border-radius: 50%;
}
.icon-text {
  font-size: 50px;
  color: #fda4af;
}
</style>
```

## 注意事项

1.  **icon 双重用途**：`icon` 属性既可作为 `m-icon` 的图标名称使用，也可传入图片 URL；具体渲染行为取决于 `m-icon` 组件对非图标名值的处理方式。若需完全自定义图片，建议使用 `#image` 插槽。
2.  **icon-size 单位**：传入纯数字时自动追加 `px` 单位；传入字符串时需自带单位（如 `'3rem'`、`'120rpx'`）。该值同时设置图标的 `font-size`、`width`、`height`，确保图标在不同平台下尺寸一致。
3.  **tip 条件渲染**：`tip` 为空字符串时，文本节点不会渲染到 DOM 中，避免产生多余的空白间距。
4.  **image 插槽优先级**：传入 `#image` 插槽后，内置的 `m-icon` 完全不渲染，`icon` 和 `icon-size` 属性对插槽内容无效。
5.  **布局依赖外部样式**：组件本身不包含居中、间距等布局样式，这些由外部 SCSS 文件（`./index.scss`）定义。若在自定义主题中使用，需确保对应样式已正确引入，否则可能出现图标与文字错位、无间距等问题。
6.  **平台差异**：组件 options 中使用了 `virtualHost: true`，该选项在头条小程序（MP-TOUTIAO）下被条件编译排除；其他平台虚拟宿主节点生效，外层不生成额外 DOM 节点。
7.  **依赖组件**：内部依赖 `m-icon` 组件，请确保项目中该组件可用且路径正确。
8.  **无交互能力**：组件为纯展示型，不提供点击、长按等交互事件；如需整体可点击，请在父级包裹可点击容器并自行绑定事件。
