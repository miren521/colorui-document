# m-toast 轻提示

全局轻量级反馈组件，支持文字、图标、Loading 等多种形态。通过 `useToast(selector)` 命令式调用，无需在模板中手动管理显隐状态。内置过渡动画、遮罩层锁定及生命周期回调。

## 快速开始

### 1. 放置容器
在页面或 App 根节点放置 `<m-toast>` 并指定唯一 `selector`：
```vue
<template>
  <m-toast selector="global" />
</template>
```

### 2. 命令式调用
```vue
<script setup lang="ts">
import { useToast } from '@/packages/m-toast'

const toast = useToast('global')

toast.show('普通提示')
toast.success('操作成功')
toast.error('操作失败')
toast.warning('请注意')
toast.info('提示信息')
toast.loading('加载中...')

// 手动关闭（常用于 loading）
toast.close()
</script>
```

## API 方法

| 方法 | 说明 | 参数 |
| :--- | :--- | :--- |
| show | 显示普通 Toast | `string \| ToastOptions` |
| success | 显示成功图标 Toast | `string \| ToastOptions` |
| error | 显示错误图标 Toast | `string \| ToastOptions` |
| warning | 显示警告图标 Toast | `string \| ToastOptions` |
| info | 显示信息图标 Toast | `string \| ToastOptions` |
| loading | 显示 Loading Toast | `string \| ToastOptions` |
| close | 立即关闭当前 Toast | - |

> 💡 传入字符串时自动作为 `msg`；传入对象时可配置全部选项。

## ToastOptions 配置项

| 参数 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| msg | 提示文本 | string | `''` |
| iconName | 内置图标类型 | `'success' \| 'error' \| 'warning' \| 'info' \| 'loading'` | - |
| iconClass | 自定义图标名称（配合 classPrefix） | string | `''` |
| cssIcon | 使用 CSS 图标（传 true 或图标类名） | boolean \| string | `false` |
| classPrefix | 图标类名前缀 | string | `'m-icon'` |
| iconSize | 图标大小（px） | number | - |
| position | 显示位置 | `'top' \| 'middle-top' \| 'middle' \| 'bottom'` | `'middle'` |
| direction | 图标与文字排列方向 | `'horizontal' \| 'vertical'` | `'horizontal'` |
| duration | 自动关闭时长（ms），0 为不自动关闭 | number | - |
| cover | 是否显示透明遮罩层（阻止穿透点击） | boolean | `false` |
| zIndex | 层级 | number | `100` |
| loadingType | Loading 图标样式 | `'circular' \| 'spinner' \| 'dots'` | `'circular'` |
| loadingColor | Loading 颜色 | string | `'#ffffff'` |
| loadingSize | Loading 大小（px） | number | - |
| opened | 入场动画完成回调 | () => void | - |
| closed | 离场动画完成回调 | () => void | - |

## 完整示例

### Loading + 手动关闭
```ts
const toast = useToast('global')

async function fetchData() {
  toast.loading('数据加载中...')
  try {
    await api.getData()
    toast.success('加载完成')
  } catch {
    toast.error('加载失败')
  }
}
```

### 自定义位置 + 垂直排列
```ts
toast.show({
  msg: '已加入购物车',
  iconName: 'success',
  position: 'bottom',
  direction: 'vertical',
  duration: 1500
})
```

### 带遮罩的确认提示
```ts
toast.show({
  msg: '处理中，请稍候...',
  iconName: 'loading',
  cover: true,       // 阻止用户操作
  duration: 0        // 不自动关闭，需手动 close
})

// 业务完成后
toast.close()
```

### 监听生命周期
```ts
toast.show({
  msg: '3秒后跳转',
  duration: 3000,
  opened: () => console.log('Toast 已显示'),
  closed: () => router.push('/next')
})
```

### 自定义 CSS 图标
```ts
toast.show({
  msg: '收藏成功',
  cssIcon: 'icon-heart-fill',  // 或使用 iconClass + classPrefix
  iconSize: 28,
  direction: 'vertical'
})
```

## 注意事项

1.  **selector 必须匹配**：`useToast('xxx')` 中的 selector 必须与模板中 `<m-toast selector="xxx" />` 一致，否则调用无效且无报错。同一页面可放置多个不同 selector 的 Toast 实例。
2.  **单例覆盖**：同一 selector 的 Toast 同时只显示一个。连续调用会立即替换前一个，前一个的 `closed` 回调**不会触发**。如需队列式提示，请使用多个 selector。
3.  **duration=0 不自动关闭**：设置 `duration: 0` 或不传 duration 时，Toast 将持续显示直到手动调用 `close()`。Loading 场景务必记得关闭，否则会永久遮挡界面。
4.  **cover 遮罩行为**：`cover=true` 时渲染透明 `m-overlay`，`pointer-events: auto` 阻止底层点击。遮罩层不参与视觉呈现，仅用于交互拦截。若需半透明背景，请自行扩展。
5.  **position 定位机制**：所有位置均基于 `position: fixed` + `top/left` 百分比实现，不依赖 flex 布局。`middle-top` 约为视口 30% 高度处，适用于避免遮挡底部导航栏的场景。
6.  **图标优先级**：`iconName='loading'` 时渲染 `m-loading` 组件；其他内置值渲染 `m-icon`；若同时设置 `iconClass` 或 `cssIcon`，则优先使用自定义图标。三者互斥，按 loading > 内置 > 自定义顺序判断。
7.  **回调时序**：`opened` 在 `m-transition` 的 `after-enter` 触发（动画完全结束）；`closed` 在 `after-leave` 触发。若 `show=false` 直接隐藏（无动画），回调仍会正常执行。
8.  **Props 与 Options 合并**：模板上绑定的 Props 作为默认值，命令式传入的 Options 优先级更高。每次调用都会重新合并，不会累积上次调用的非默认值。
9.  **虚拟宿主兼容**：启用 `virtualHost: true`（头条小程序除外）。在头条小程序中 Toast 会产生额外包裹节点，可能影响 fixed 定位，建议在该平台测试验证。
10. **z-index 冲突**：默认 `zIndex=100`，低于 `m-popup`（2000）等组件。若 Toast 被弹窗遮挡，请调高 zIndex 或在弹窗关闭后再显示 Toast。
