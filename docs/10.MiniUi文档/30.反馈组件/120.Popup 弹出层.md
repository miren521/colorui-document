# m-popup 弹出层

用于从屏幕边缘或中心弹出内容面板的容器组件，支持五个方向定位、遮罩层控制、关闭按钮、安全区适配及自定义过渡动画。通过 `v-model` 双向绑定显隐状态，内置滚动锁定与懒渲染优化。

## 基本用法

```vue
<template>
  <m-button @click="visible = true">打开弹窗</m-button>
  
  <m-popup v-model="visible" position="bottom">
    <view style="padding: 20px;">
      <text>弹窗内容</text>
      <m-button @click="visible = false">关闭</m-button>
    </view>
  </m-popup>
</template>

<script setup lang="ts">
import { ref } from 'vue'
const visible = ref(false)
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| model-value / v-model | 是否显示弹窗 | boolean | `false` |
| position | 弹出位置 | `'center' \| 'top' \| 'bottom' \| 'left' \| 'right'` | `'center'` |
| closable | 是否显示右上角关闭按钮 | boolean | `false` |
| close-on-click-modal | 点击遮罩层是否关闭弹窗 | boolean | `true` |
| duration | 过渡动画时长（ms） | number | `300` |
| z-index | 弹窗层级（遮罩层为 zIndex，内容层为 zIndex+1） | number | `2000` |
| modal | 是否显示遮罩层 | boolean | `true` |
| modal-style | 遮罩层自定义样式 | string \| object | - |
| custom-style | 弹窗容器自定义样式 | string \| object | - |
| content-style | 内容区域自定义样式 | string \| object | - |
| safe-area-inset-bottom | 是否开启底部安全区适配 | boolean | `false` |
| lock-scroll | 是否锁定背景滚动 | boolean | `true` |
| lazy-render | 是否懒渲染（首次打开才挂载 DOM） | boolean | `true` |
| hide-when-close | 关闭动画结束后是否移除 DOM | boolean | `true` |
| transition | 自定义过渡动画名称（预留，当前未实现） | string | - |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| update:model-value | 显隐状态变化时触发（v-model 更新） | value: boolean |
| open | 弹窗开始打开时触发（DOM 已渲染，动画开始前） | - |
| opened | 打开动画完成后触发 | - |
| close | 弹窗开始关闭时触发 | - |
| closed | 关闭动画完成且 DOM 移除后触发 | - |
| click-modal | 点击遮罩层时触发（无论是否关闭弹窗） | - |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 弹窗主体内容 |
| header | 顶部区域，位于关闭按钮下方、内容区上方 |
| footer | 底部区域，位于内容区下方 |

## 完整示例

### 五向弹出 + 关闭按钮
```vue
<m-popup v-model="show" position="center" closable>
  <template #header><text class="title">标题</text></template>
  <text>居中弹窗内容</text>
  <template #footer>
    <m-button block @click="show = false">确定</m-button>
  </template>
</m-popup>
```

### 侧边栏抽屉
```vue
<m-popup 
  v-model="drawerVisible" 
  position="right" 
  :custom-style="{ width: '300px', height: '100%' }"
  :safe-area-inset-bottom="true"
>
  <view class="drawer-content">侧边导航</view>
</m-popup>
```

### 禁止遮罩关闭 + 监听生命周期
```vue
<m-popup 
  v-model="confirmShow" 
  :close-on-click-modal="false"
  @opened="onOpened"
  @closed="onClosed"
>
  <text>必须点击按钮才能关闭</text>
  <m-button @click="confirmShow = false">确认</m-button>
</m-popup>
```

### 自定义遮罩与内容样式
```vue
<m-popup 
  v-model="visible"
  :modal-style="{ background: 'rgba(0,0,0,0.8)' }"
  :content-style="{ padding: '0' }"
  :custom-style="{ borderRadius: '16px', overflow: 'hidden' }"
>
  <image src="/banner.jpg" mode="widthFix" />
</m-popup>
```

## 注意事项

1.  **v-model 双向绑定**：必须使用 `v-model` 或 `:model-value` + `@update:model-value` 控制显隐。直接修改内部状态无效。
2.  **动画时序**：`open` 在 DOM 渲染后、动画前触发；`opened` 在 `duration` 毫秒后触发。关闭流程同理。若需在动画完成后执行逻辑（如聚焦输入框），请监听 `opened` 而非 `open`。
3.  **懒渲染机制**：`lazy-render=true`（默认）时，弹窗首次打开前不渲染 DOM，减少初始开销。关闭后若 `hide-when-close=true`，DOM 会被移除；设为 `false` 则保留 DOM 仅隐藏，适合频繁开关的场景。
4.  **滚动锁定平台差异**：
    -   **H5**：通过 `useLockScroll` 组合函数禁用 body 滚动。
    -   **小程序**：通过 `catchtouchmove="noop"` 阻止遮罩层触摸穿透。注意：此方式仅对遮罩层生效，若弹窗内容本身可滚动，需在内容区单独处理滚动边界。
5.  **z-index 层级管理**：内容层 z-index 始终比遮罩层高 1。多弹窗叠加时，请手动递增 `z-index` 避免遮挡错乱。
6.  **safe-area-inset-bottom**：仅添加 `padding-bottom: env(safe-area-inset-bottom)`，适用于 iPhone X+ 底部横条避让。若需顶部安全区，请自行在 `custom-style` 中添加。
7.  **关闭按钮图标**：当前硬编码使用 `plus` 图标并旋转 45° 作为关闭符号（由 SCSS 控制）。如需更换，请隐藏默认按钮并通过 `header` 插槽自定义。
8.  **custom-style 对象格式**：支持 camelCase 键名（如 `borderRadius`），内部自动转换为 kebab-case。字符串格式则直接拼接，需注意末尾分号。
9.  **transition 属性预留**：当前版本所有位置均使用 CSS 类切换实现固定动画，`transition` 属性尚未接入自定义动画逻辑。如需自定义动效，请覆盖 `.m-popup--*` 相关 SCSS 类。
10. **点击事件冒泡**：弹窗内容区已设置 `@tap.stop` 阻止冒泡至遮罩层，避免误触关闭。若需在内容区内触发遮罩层事件，请手动派发。
