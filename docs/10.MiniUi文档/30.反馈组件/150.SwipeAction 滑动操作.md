# m-swipe-action 滑动操作

为列表项或卡片提供左右滑动呼出操作按钮的交互容器，支持双向滑动、多按钮、关闭前拦截钩子及队列互斥管理。通过 `v-model` 控制展开状态，内置触摸方向识别与阈值吸附逻辑。

## 基本用法

```vue
<template>
  <m-swipe-action v-model="status">
    <view class="content">向左滑动</view>
    <template #right>
      <view class="btn-delete" @click="onDelete">删除</view>
    </template>
  </m-swipe-action>
</template>

<script setup lang="ts">
import { ref } from 'vue'
const status = ref('close')
function onDelete() { /* ... */ }
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| model-value / v-model | 当前滑动状态 | `'left' \| 'close' \| 'right'` | `'close'` |
| disabled | 是否禁用滑动和点击交互 | boolean | `false` |
| before-close | 关闭前拦截钩子，返回 `true`/`Promise<true>` 才允许关闭 | `(reason, position) => boolean \| Promise<boolean>` | - |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| update:model-value | 滑动状态变化时触发 | value: `'left' \| 'close' \| 'right'` |
| click | 点击内容区或操作按钮时触发 | `{ value: 'left' \| 'right' \| 'inside' }` |

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 主内容区域（不可滑动的主体部分） |
| left | 左侧滑出的操作按钮组 |
| right | 右侧滑出的操作按钮组 |

## 暴露方法（Expose）

| 方法名 | 说明 | 参数 |
| :--- | :--- | :--- |
| close | 手动关闭已展开的操作菜单 | `reason: SwipeActionReason, position?: SwipeActionPosition` |

```vue
<m-swipe-action ref="swipeRef">...</m-swipe-action>
<script setup>
const swipeRef = ref()
swipeRef.value.close('click', 'right')
</script>
```

## beforeClose 钩子详解

```ts
type SwipeActionBeforeClose = (
  reason: 'click' | 'swipe' | 'value',  // 触发关闭的原因
  position: 'left' | 'right' | 'inside' // 操作发生的位置
) => boolean | Promise<boolean>
```

-   **reason='click'**：用户点击了操作按钮或内容区
-   **reason='swipe'**：用户反向滑动或滑动未达阈值自动回弹
-   **reason='value'**：外部通过 `v-model` 或 `close()` 主动修改状态

返回 `false` 或不返回值将**阻止本次关闭**，保持当前展开状态。支持异步（如弹窗确认）：

```vue
<m-swipe-action :before-close="confirmDelete">
  <template #right><view @click="onDelete">删除</view></template>
</m-swipe-action>

<script setup>
async function confirmDelete(reason, position) {
  if (position === 'right' && reason === 'click') {
    return await showModal('确定删除？')
  }
  return true
}
</script>
```

## 完整示例

### 双向滑动 + 多按钮
```vue
<m-swipe-action v-model="status">
  <view class="item-content">{{ item.title }}</view>
  <template #left>
    <view class="btn-pin" @click="onPin">置顶</view>
  </template>
  <template #right>
    <view class="btn-edit" @click="onEdit">编辑</view>
    <view class="btn-del" @click="onDelete">删除</view>
  </template>
</m-swipe-action>
```

### 列表互斥（自动关闭其他项）
组件内部通过全局队列（`useQueue` / `pushToQueue`）实现互斥：同一页面内多个 `m-swipe-action` 实例在滑动时会自动关闭其他已展开项，无需手动处理。若使用了自定义 `queueKey` 注入，则仅在相同队列内互斥。

### 手动程序化控制
```vue
<m-button @click="status = 'right'">展开右侧</m-button>
<m-button @click="status = 'close'">关闭</m-button>
<m-swipe-action v-model="status">...</m-swipe-action>
```

## 注意事项

1.  **v-model 必填**：组件为受控模式，必须绑定 `v-model` 或 `:model-value` + `@update:model-value`。未绑定时手势仍可拖动但状态不会持久化，松手后回弹异常。
2.  **操作按钮宽度自适应**：左右插槽内容的宽度由实际渲染决定，组件在每次滑动开始时动态测量（`getRect`）。若按钮内容异步加载或延迟渲染，可能导致首次滑动宽度计算为 0。建议在数据就绪后再启用滑动。
3.  **阈值吸附**：松手时若滑动距离超过对应侧宽度的 **30%**，则吸附至完全展开；否则回弹关闭。该阈值为硬编码常量，不可配置。
4.  **垂直滚动兼容**：`useTouch` 会判断滑动方向，垂直滑动时不拦截事件，保证列表可正常滚动。仅水平方向触发 `preventDefault`。
5.  **点击事件区分**：`@click` 事件的 `value` 字段标识点击来源：`'left'`/`'right'` 表示操作按钮，`'inside'` 表示主内容区。可在回调中据此分发不同逻辑。
6.  **disabled 行为**：禁用后不仅阻止手势滑动，还会忽略所有点击事件和 `v-model` 变更。若仅需临时禁止手势但保留程序化控制，请改用条件判断而非 `disabled`。
7.  **队列互斥范围**：默认使用全局单例队列，整个应用内所有 `m-swipe-action` 互斥。若需在特定区域内独立互斥（如多个 Tab 页各自管理），可通过 `provide(queueKey, customQueue)` 注入独立队列实例。
8.  **动画时序**：拖拽过程中 `transition: none` 保证跟手流畅；松手后切换为 `.6s cubic-bezier(0.18, 0.89, 0.32, 1)` 弹性回弹。该曲线和时长为固定值，如需自定义请覆盖 `.m-swipe-action__wrapper` 的 CSS。
9.  **虚拟宿主**：启用 `virtualHost: true`（头条小程序除外），`custom-class/style` 直接作用于根节点。在头条小程序中会生成额外包裹层，注意布局影响。
10. **beforeClose 与 click 事件顺序**：`beforeClose` 先于 `@click` 执行。若钩子返回 `false` 阻止关闭，`@click` 事件**仍会触发**。如需在拦截时同时阻止业务逻辑，请在 `@click` 回调中额外检查当前状态。
