# m-action-sheet 上拉菜单

从底部弹出的操作菜单组件，支持操作列表（actions）和宫格面板（panels）两种内容形式，可配置标题、取消按钮、点击关闭等行为。基于 `m-popup` 实现，需配合 `v-model` 控制显隐。

## 基本用法

```vue
<template>
  <m-button type="primary" @click="show = true">弹出菜单</m-button>
  <m-action-sheet
    v-model="show"
    :actions="actions"
    cancel-text="取消"
    @select="onSelect"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import mActionSheet from '@/packages/m-action-sheet/m-action-sheet.vue'
import type { Action } from '@/packages/m-action-sheet/types'

const show = ref(false)

const actions: Action[] = [
  { name: '选项一' },
  { name: '选项二' },
  { name: '选项三' }
]

function onSelect(e: { item: Action; index: number }) {
  console.log(e.item.name, e.index)
}
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| model-value | 是否显示菜单，支持 `v-model` | boolean | `false` |
| actions | 操作选项列表，每项为 `Action` 对象（见下方类型说明） | Action[] | `[]` |
| panels | 宫格面板数据，每项为 `Panel` 对象；支持一维数组（单行）或二维数组（多行） | Panel[] \| Panel[][] | `[]` |
| title | 标题文本，设置后标题右侧显示关闭按钮 | string | 源码中未明确说明 |
| cancel-text | 取消按钮文本，为空字符串时不显示取消按钮 | string | 源码中未明确说明 |
| close-on-click-action | 点击选项后是否自动关闭菜单 | boolean | `true` |
| close-on-click-modal | 点击遮罩是否关闭菜单 | boolean | `true` |
| duration | 弹出动画时长，单位 ms | number | `200` |
| z-index | 层级 | number | `10` |
| lazy-render | 是否懒渲染（首次显示时才渲染内容） | boolean | `true` |
| safe-area-inset-bottom | 是否开启底部安全区适配 | boolean | `true` |
| root-portal | 是否将整个组件挂载到根节点（脱离当前页面节点层级） | boolean | `false` |
| lock-scroll | 是否锁定背景滚动 | boolean | `true` |
| custom-class | 自定义内容区类名 | string | `''` |
| custom-style | 自定义内容区样式 | string | `''` |
| custom-title-class | 自定义标题区类名 | string | `''` |

### 类型说明

```ts
// 操作选项
type Action = {
  name: string          // 选项名称
  description?: string  // 选项描述（二级文本）
  color?: string        // 选项文字颜色
  disabled?: boolean    // 是否禁用，禁用时点击不触发 select
  loading?: boolean     // 是否显示加载中，加载中时点击不触发 select
  [key: string]: any    // 允许携带自定义字段
}

// 宫格面板项
type Panel = {
  icon: string   // 图标名称（对应 m-icon 的 name）
  title: string  // 面板项标题
}
```

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| select | 点击选项（action 或 panel）时触发；disabled 或 loading 状态的 action 不触发 | 见下方说明 |
| cancel | 点击取消按钮时触发 | - |
| close | 菜单关闭时触发（点击标题关闭按钮、取消按钮、遮罩等关闭操作均会触发） | - |
| click-modal | 点击遮罩时触发 | - |
| enter | 弹出动画开始时触发（透传自 m-popup） | - |
| after-enter | 弹出动画结束时触发（透传自 m-popup） | - |
| leave | 关闭动画开始时触发（透传自 m-popup） | - |
| after-leave | 关闭动画结束时触发（透传自 m-popup） | - |
| update:modelValue | 菜单显示状态变化时触发 | value: boolean |

**select 事件回调参数**：

- 点击 action 项时：`{ item: Action, index: number }`
- 点击一维 panels 项时：`{ item: Panel, index: number }`
- 点击二维 panels 项时：`{ item: Panel, rowIndex: number, colIndex: number }`

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 自定义菜单内容，传入后内置的 actions 和 panels 均不渲染；取消按钮仍正常显示 |
| close | 自定义标题右侧的关闭按钮，插槽参数为 `{ close: () => void }`，可调用 `close` 关闭菜单 |

## 方法（Methods）

源码中未通过 ref 暴露任何方法。关闭菜单通过 `v-model` 设置为 `false` 实现；`close` 插槽提供了 `close` 方法作为插槽参数。

## 完整示例

```vue
<template>
  <!-- 基础用法：操作列表 + 取消按钮 -->
  <m-button type="primary" @click="showBasic = true">基础操作</m-button>
  <m-action-sheet
    v-model="showBasic"
    :actions="basicActions"
    cancel-text="取消"
    @select="onSelect"
  />

  <!-- 带标题 -->
  <m-action-sheet
    v-model="showTitle"
    title="请选择操作"
    :actions="basicActions"
    cancel-text="取消"
  />

  <!-- 带描述、禁用、颜色、加载状态 -->
  <m-action-sheet
    v-model="showDesc"
    :actions="[
      { name: '保存图片', description: '将图片保存到相册' },
      { name: '删除图片', description: '删除后无法恢复', color: '#ee0a24' },
      { name: '禁用选项', disabled: true },
      { name: '加载中', loading: true }
    ]"
    cancel-text="取消"
  />

  <!-- 宫格面板（一维数组，单行） -->
  <m-action-sheet
    v-model="showPanel"
    :panels="panelData"
    cancel-text="取消"
    @select="onPanelSelect"
  />

  <!-- 宫格面板（二维数组，多行） -->
  <m-action-sheet
    v-model="showMultiPanel"
    :panels="[
      [
        { icon: 'user', title: '好友' },
        { icon: 'qrcode', title: '二维码' },
        { icon: 'save', title: '保存' },
        { icon: 'delete', title: '删除' }
      ],
      [
        { icon: 'copy', title: '复制' },
        { icon: 'share', title: '分享' }
      ]
    ]"
    cancel-text="取消"
    @select="onPanelSelect"
  />

  <!-- 危险操作场景：不显示取消按钮 -->
  <m-action-sheet
    v-model="showDelete"
    title="确认删除"
    :actions="[
      { name: '删除', color: '#ee0a24', description: '删除后无法恢复' },
      { name: '取消' }
    ]"
    :cancel-text="''"
  />

  <!-- 自定义关闭按钮 -->
  <m-action-sheet v-model="showCustom" title="自定义标题">
    <template #close="{ close }">
      <view class="custom-close" @click="close">收起</view>
    </template>
    <view class="custom-content">自定义内容</view>
  </m-action-sheet>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import mActionSheet from '@/packages/m-action-sheet/m-action-sheet.vue'
import type { Action, Panel } from '@/packages/m-action-sheet/types'

const showBasic = ref(false)
const showTitle = ref(false)
const showDesc = ref(false)
const showPanel = ref(false)
const showMultiPanel = ref(false)
const showDelete = ref(false)
const showCustom = ref(false)

const basicActions: Action[] = [
  { name: '选项一' },
  { name: '选项二' },
  { name: '选项三' }
]

const panelData: Panel[] = [
  { icon: 'user', title: '好友' },
  { icon: 'qrcode', title: '二维码' },
  { icon: 'save', title: '保存' },
  { icon: 'delete', title: '删除' },
  { icon: 'copy', title: '复制' }
]

function onSelect(e: { item: Action; index: number }) {
  console.log('选中操作:', e.item.name, e.index)
}

function onPanelSelect(e: { item: Panel; index?: number; rowIndex?: number; colIndex?: number }) {
  console.log('选中面板:', e.item.title)
}
</script>

<style scoped lang="scss">
.custom-close {
  font-size: 14px;
  color: #1989fa;
  padding: 0 16px;
}
.custom-content {
  padding: 32px 16px;
  text-align: center;
}
</style>
```

## 注意事项

1.  **panels 格式自动识别**：组件通过判断 `panels[0]` 是否为数组来区分一维/二维格式。一维数组视为单行宫格；二维数组视为多行宫格。一维和二维格式下 `select` 事件的回调参数结构不同（一维返回 `index`，二维返回 `rowIndex` + `colIndex`），使用时需注意区分。
2.  **actions 与 panels 可同时使用**：两者都传入时，actions 列表渲染在上方，panels 宫格渲染在下方。
3.  **默认插槽优先级**：传入默认插槽后，内置的 actions 和 panels 均不渲染，但标题栏和取消按钮仍正常显示。
4.  **弹出背景透明处理**：当传入了非空的 `actions` 或 `panels` 时，内部 `m-popup` 背景设为透明（由内容区自行绘制背景）；仅使用默认插槽自定义内容且未传 actions/panels 时，popup 保留默认背景。
5.  **disabled / loading 拦截**：处于 `disabled` 或 `loading` 状态的 action 点击时不会触发 `select` 事件，也不会因 `close-on-click-action` 关闭菜单。
6.  **依赖组件**：内部依赖 `m-popup`、`m-icon`、`m-loading`，请确保项目中这些组件可用。
7.  **root-portal**：默认关闭；在小程序中若遇到层级（如 cover-view、原生组件）遮挡问题，可开启该属性将组件挂载到根节点，具体行为取决于 `m-popup` 的实现及各平台支持情况。
8.  **cancel-text 判断**：取消按钮通过 `v-if="cancelText"` 控制，传入空字符串 `''` 即可隐藏取消按钮；不传时同样不显示。
