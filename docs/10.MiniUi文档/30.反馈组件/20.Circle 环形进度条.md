# m-circle 环形进度条

基于 Canvas 实现的环形进度条组件，支持自定义尺寸、颜色、渐变、动画速度及顺时针/逆时针方向，适用于数据可视化、加载状态等场景。

## 基本用法

```vue
<template>
  <m-circle :model-value="50" />
</template>

<script setup lang="ts">
import mCircle from '@/packages/m-circle/m-circle.vue'
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| model-value | 当前进度百分比，范围 0-100 | number | `0` |
| size | 圆环直径，单位为 px | number | `120` |
| color | 进度条颜色，传入字符串为纯色，传入对象（如 `{ '0': '#ff6b6b', '100': '#4ecdc4' }`）为渐变色 | string \| Record | `'#1C64FD'` |
| layer-color | 轨道背景颜色 | string | `'#F2F3F5'` |
| stroke-width | 进度条宽度，单位为 px | number | `18` |
| speed | 动画速度，单位 rate/s，值越大动画越快；≤0 或 >1000 时无动画直接渲染 | number | `50` |
| text | 中心自定义文字，设置后默认插槽失效 | string | 源码中未明确说明 |
| stroke-linecap | 进度条端点形状 | `'butt' \| 'round' \| 'square'` | `'round'` |
| clockwise | 是否顺时针增加 | boolean | `true` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

## 事件（Events）

源码中未定义任何事件。

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| default | 自定义中心内容，当 `text` 属性为空时生效；默认显示 `XX%` 百分比文字 |

## 方法（Methods）

源码中未通过 ref 暴露任何方法。

## 完整示例

```vue
<template>
  <!-- 基础用法 -->
  <view class="row">
    <m-circle :model-value="30" />
    <m-circle :model-value="50" />
    <m-circle :model-value="70" />
  </view>

  <!-- 自定义颜色 -->
  <view class="row">
    <m-circle :model-value="50" color="#ff6b6b" />
    <m-circle :model-value="50" color="#4ecdc4" />
  </view>

  <!-- 渐变色 -->
  <view class="row">
    <m-circle :model-value="50" :color="{ '0': '#ff6b6b', '100': '#4ecdc4' }" />
    <m-circle :model-value="70" :color="{ '0': '#667eea', '50': '#764ba2', '100': '#f093fb' }" />
  </view>

  <!-- 自定义宽度与大小 -->
  <view class="row">
    <m-circle :model-value="50" :stroke-width="6" />
    <m-circle :model-value="50" :size="80" />
    <m-circle :model-value="50" :size="160" />
  </view>

  <!-- 自定义文字 -->
  <view class="row">
    <m-circle :model-value="30" text="进行中" color="#e6a23c" />
    <m-circle :model-value="100" text="已完成" color="#67c23a" />
  </view>

  <!-- 插槽内容 -->
  <view class="row">
    <m-circle :model-value="75">
      <view class="slot-content">
        <text class="slot-percent">75%</text>
        <text class="slot-label">存储空间</text>
      </view>
    </m-circle>
  </view>

  <!-- 动态改变 -->
  <view class="row">
    <m-circle :model-value="dynamicValue" />
  </view>
  <view class="btn-row">
    <button @click="dynamicValue = 30">30%</button>
    <button @click="dynamicValue = 70">70%</button>
    <button @click="dynamicValue = 100">100%</button>
  </view>

  <!-- 逆时针 -->
  <view class="row">
    <m-circle :model-value="50" :clockwise="false" />
  </view>

  <!-- 端点形状 -->
  <view class="row">
    <m-circle :model-value="50" stroke-linecap="butt" />
    <m-circle :model-value="50" stroke-linecap="round" />
  </view>

  <!-- 动画速度 -->
  <view class="row">
    <m-circle :model-value="speedValue" :speed="speed" />
  </view>
  <view class="btn-row">
    <button @click="setSpeed(10)">慢速</button>
    <button @click="setSpeed(200)">快速</button>
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import mCircle from '@/packages/m-circle/m-circle.vue'

const dynamicValue = ref(30)
const speedValue = ref(0)
const speed = ref(50)

function setSpeed(val: number) {
  speed.value = val
  speedValue.value = 0
  setTimeout(() => {
    speedValue.value = 100
  }, 50)
}
</script>

<style scoped lang="scss">
.row {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
  margin-bottom: 24px;
}
.btn-row {
  display: flex;
  justify-content: center;
  gap: 12px;
  flex-wrap: wrap;
}
.slot-content {
  display: flex;
  flex-direction: column;
  align-items: center;
}
.slot-percent {
  font-size: 28px;
  font-weight: 600;
}
.slot-label {
  font-size: 12px;
  color: #999;
}
</style>
```

## 注意事项

1.  **平台差异**：微信小程序使用 Canvas 2D API（`type="2d"`），并通过 `canvas2dAdapter` 适配上下文；其他平台使用旧版 `uni.createCanvasContext`。微信小程序下首次渲染有 50ms 延迟以确保 Canvas 节点就绪。
2.  **渐变色格式**：`color` 传入对象时，key 为百分比字符串（如 `'0'`、`'50'`、`'100'`），value 为颜色值，组件会按 key 数值排序后生成线性渐变。
3.  **文字颜色联动**：当 `color` 为字符串时，中心文字颜色自动同步为 `color` 的值；当 `color` 为渐变对象时，文字颜色回退为 `#646a73`。
4.  **动画机制**：`speed` 控制每秒更新的步数，内部以固定步长 `STEP=1` 递增/递减；`speed ≤ 0` 或 `speed > 1000` 时跳过动画直接绘制目标值。
5.  **尺寸单位**：`size` 和 `stroke-width` 仅支持数字，单位为 px；如需响应式尺寸需自行换算后传入。
6.  **Canvas ID**：每个实例自动生成唯一 canvas-id，同一页面可安全使用多个 `m-circle`。
7.  **生命周期清理**：组件卸载时会自动清除动画定时器，避免内存泄漏。
8.  **strokeLinecap 类型定义不一致**：types 文件中注释标注可选值为 `'butt' | 'round'`，但实际 PropType 定义为 `'butt' | 'round' | 'square'`，三个值均可正常使用。
