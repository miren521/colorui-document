`m-notify` 是通知功能的底层渲染组件，通常不直接在模板中使用，而是通过 `useNotify(selector)` 组合函数命令式调用。它基于 `m-popup` 实现弹出动画与定位，内部通过 Vue `inject/provide` 机制接收状态，支持多种类型、位置、浮动形态及自定义样式。


## 基本用法（直接引用）

```vue
<template>
  <m-notify selector="my-notify" />
</template>

<script setup lang="ts">
import { useNotify } from '@/packages/m-notify'

const { showNotify, closeNotify } = useNotify('my-notify')

showNotify({ message: 'Hello', type: 'success' })
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| selector | 通知实例标识，需与 `useNotify(selector)` 参数一致 | string | `''` |
| visible | 是否显示通知（由 `useNotify` 内部控制，一般无需手动传） | boolean | `false` |
| type | 通知类型，决定默认图标和主题色 | `'primary' \| 'success' \| 'danger' \| 'warning'` | `'danger'` |
| message | 通知内容，支持 `\n` 换行 | string \| number | `''` |
| position | 显示位置 | `'top' \| 'bottom'` | `'top'` |
| variant | 显示形态 | `'filled' \| 'floating'` | `'filled'` |
| duration | 自动关闭时长（ms），`0` 表示不自动关闭 | number | `3000` |
| color | 自定义文字颜色 | string | `''` |
| background | 自定义背景色/渐变 | string | `''` |
| zIndex | 弹层层级 | number | `99` |
| safeHeight | 顶部安全区偏移高度（仅 position='top' 时生效） | number | 源码中未明确说明 |
| closable | 是否显示关闭按钮 | boolean | `false` |
| rootPortal | 是否使用 root-portal 将弹窗挂载到页面根节点 | boolean | `false` |
| custom-class | 自定义外层容器类名 | string | `''` |
| custom-style | 自定义外层容器样式 | string | `''` |

### type 默认图标映射

| type | 图标名 |
| :--- | :--- |
| success | check-circle-fill |
| warning | exclamation-circle-fill |
| danger | close-circle-fill |
| primary / 其他 | info-circle-fill |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| update:visible | visible 变化时触发（v-model 双向绑定） | value: boolean |
| click | 点击通知内容区域 | event: MouseEvent |
| opened | 入场动画完成 | - |
| closed | 离场动画完成 | - |

> 💡 当通过 `useNotify` 传入 `onClick` / `onOpened` / `onClosed` 回调时，组件内部优先执行回调，不再 emit 对应事件。

## 插槽（Slots）

| 插槽名 | 说明 |
| :--- | :--- |
| prefix | 自定义左侧图标区域，传入后 type 默认图标不渲染 |
| default | 自定义通知内容，传入后 message 属性不渲染 |
| close | 自定义关闭按钮，仅在 closable=true 时生效 |

## 方法（Methods）

组件本身未通过 ref 暴露方法。所有控制逻辑通过 `useNotify(selector)` 返回的 `showNotify` / `closeNotify` 完成。

## 完整示例（二次封装场景）

```vue
<template>
  <!-- 自定义前缀图标 + 富文本内容 -->
  <m-notify selector="custom">
    <template #prefix>
      <image src="/static/bell.png" style="width: 20px; height: 20px;" />
    </template>
    <text class="rich-msg">订单 <text style="color:#ff6b6b">#20240101</text> 已发货</text>
  </m-notify>
</template>

<script setup lang="ts">
import { useNotify } from '@/packages/m-notify'

const { showNotify } = useNotify('custom')

// 即使使用了插槽，仍需调用 showNotify 触发显示
showNotify({ message: '', type: 'success', duration: 5000 })
</script>
```

## 注意事项

1.  **selector 唯一性**：同一页面内多个 `<m-notify>` 必须使用不同的 `selector`，每个 selector 对应独立的 `useNotify` 实例和状态通道。重复 selector 会导致状态冲突。
2.  **state 注入机制**：组件通过 `inject(getNotifyOptionKey(selector))` 获取响应式状态，该状态由 `useNotify` 内部 provide。若未调用 `useNotify` 或 selector 不匹配，组件将回退到 props 初始值，且无法响应命令式调用。
3.  **popup 依赖**：通知的进出动画、遮罩（本组件固定 `modal=false`）、z-index、root-portal 等均由内部 `m-popup` 处理。修改这些行为需了解 `m-popup` 的实现细节。
4.  **safeHeight 用途**：仅 `position='top'` 时生效，用于避开导航栏、状态栏等区域。值为数字，内部自动添加 px 单位；也可通过 CSS 变量 `--window-top` 配合 calc 自适应。
5.  **floating 形态布局**：`variant='floating'` 时，popup 的 left/right 设为 CSS 变量 `--m-notify-floating-margin-horizontal`（默认 12px），宽度 auto，实现两侧留白的卡片效果。可通过全局覆盖该变量统一调整间距。
6.  **事件与回调互斥**：若在 `showNotify(options)` 中传入了 `onClick` / `onOpened` / `onClosed`，组件不会 emit 同名事件。两种方式择一使用，避免重复处理。
7.  **message 类型**：虽然 prop 定义为 `numericProp`（string | number），但实际渲染为文本。传入数字时会自动转为字符串；复杂内容请使用 default 插槽。
8.  **平台差异**：`virtualHost: true` 在头条小程序下被条件编译排除；`root-portal` 仅在支持该平台特性的环境中生效，否则降级为普通定位。
9.  **样式隔离**：组件设置 `styleIsolation: 'shared'`，允许外部样式穿透影响内部元素。自定义主题时可直接覆盖 `.m-notify__*` 类名，但需注意作用域污染。
10. **无遮罩层**：组件硬编码 `:modal="false"`，不支持开启遮罩。如需带遮罩的通知，应改用 `m-popup` 或其他弹窗组件自行实现。
