# m-progress 进度条

用于展示操作或任务当前进度的线性指示器，支持动态动画、渐变/分段颜色、状态图标及文字位置自定义。通过 `percentage` 驱动进度变化，内置平滑过渡与颜色切换逻辑。

## 基本用法

```vue
<template>
  <m-progress :percentage="50" />
</template>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| percentage | 当前进度百分比（0-100） | number | `0` |
| color | 进度条颜色，支持纯色、渐变数组或分段颜色对象数组 | string \| string[] \| ProgressColor[] | - |
| status | 预设状态，自动应用对应主题色和图标 | `'success' \| 'danger' \| 'warning'` | - |
| stroke-width | 进度条高度（px） | number | `8` |
| duration | 进度每变化 1% 所需的动画时长（ms） | number | `30` |
| hide-text | 是否隐藏百分比文字 | boolean | `false` |
| percent-position | 文字显示位置与对齐方式 | PercentPosition | `{ type: 'outer', align: 'right' }` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

### PercentPosition 类型

```ts
type PercentPosition = {
  type?: 'inner' | 'outer'  // 文字在进度条内部还是外部
  align?: 'left' | 'center' | 'right'  // 文字对齐方式
}
```

### ProgressColor 类型（分段颜色）

```ts
type ProgressColor = {
  color: string      // 颜色值
  percentage: number // 该颜色生效的进度阈值
}
```

## color 三种模式详解

| 模式 | 格式 | 行为 |
| :--- | :--- | :--- |
| 纯色 | `string` | 整个进度条使用单一颜色 |
| 渐变 | `string[]`（全为字符串） | 生成 `linear-gradient(to right, ...)` 背景，随进度宽度裁切显示 |
| 分段 | `ProgressColor[]` | 按 `percentage` 升序排列，进度到达各阈值时切换对应颜色，带独立动画过渡 |

> ⚠️ **混合类型禁止**：数组元素必须全部为字符串或全部为 `ProgressColor` 对象，否则抛出错误。

## 完整示例

### 渐变色
```vue
<m-progress :percentage="60" :color="['#ff0000', '#00ff00', '#0000ff']" />
```

### 分段颜色（动态切换）
```vue
<template>
  <m-progress 
    :percentage="pct" 
    :color="[
      { color: '#ff4d4f', percentage: 30 },
      { color: '#faad14', percentage: 70 },
      { color: '#52c41a', percentage: 100 }
    ]" 
  />
  <m-button @click="pct = 15">15%</m-button>
  <m-button @click="pct = 85">85%</m-button>
</template>

<script setup lang="ts">
import { ref } from 'vue'
const pct = ref(30)
</script>
```

### 状态 + 内嵌文字
```vue
<m-progress 
  :percentage="100" 
  status="success" 
  :stroke-width="20"
  :percent-position="{ type: 'inner', align: 'center' }"
/>
```

### 隐藏文字仅显示状态图标
```vue
<m-progress :percentage="50" status="danger" :hide-text="true" />
```

## 注意事项

1.  **percentage 校验**：值必须在 0–100 之间，超出范围会在控制台输出错误提示，但不会阻断渲染。建议业务层提前 clamp 处理。
2.  **duration 含义**：表示 **每 1% 变化所需毫秒数**，而非总动画时长。例如 `duration=30` 时，从 0% 到 100% 需要 3000ms。分段颜色切换时，每段动画时长 = 该段进度差 × duration。
3.  **分段颜色动画机制**：组件通过定时器逐段推进进度并切换颜色，确保视觉连续性。若频繁修改 `percentage`，前一段动画未完成时会中断并重新计算路径。避免在极短时间内高频更新。
4.  **渐变模式限制**：`color` 为字符串数组时，直接使用 CSS `linear-gradient`，**不触发分段动画逻辑**。进度变化仅有宽度过渡，颜色始终完整渐变。
5.  **status 与 color 优先级**：同时设置 `status` 和 `color` 时，`color` 优先级更高，会覆盖 status 对应的预设色。但 status 仍会渲染对应图标（除非 `hide-text=true` 且无 inner 文字）。
6.  **inner 文字可读性**：`percent-position.type='inner'` 时，文字叠加在进度条上方。当 `stroke-width` 过小（<16px）或进度较低时，文字可能溢出或被裁切。建议搭配足够高度或使用 `align: 'right'` 让文字跟随进度末端。
7.  **hide-text 与 status 图标**：`hide-text=true` 时，百分比文字隐藏，但若设置了 `status`，仍会显示对应状态图标。若需完全隐藏所有内容，请同时移除 `status`。
8.  **动画暂停工具**：内部使用 `pause()` 微任务延迟确保 DOM 更新后再启动 CSS transition。若自定义了全局异步调度器，请注意兼容性。
9.  **零进度样式**：`percentage=0` 时自动添加 `.is-zero` 类，可用于隐藏初始状态的进度条或调整布局占位。
10. **平台兼容**：渐变背景依赖 CSS `linear-gradient`，所有现代小程序及 H5 均支持。分段颜色的定时器动画在低端设备上可能出现卡顿，可适当增大 `duration` 缓解。
