# m-sort-button 排序按钮

用于列表、表格等场景的排序切换控件，通过点击循环切换升序、降序和重置状态。支持 `v-model` 双向绑定排序值，可配置优先降序、允许重置及下划线样式。

## 基本用法

```vue
<template>
  <m-sort-button title="价格" v-model="sortValue" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const sortValue = ref(0) // 0=未排序, 1=升序, -1=降序
</script>
```

## 属性（Props）

| 参数名 | 说明 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| model-value / v-model | 当前排序方向：`1`=升序，`-1`=降序，`0`=未排序/重置 | `-1 \| 0 \| 1` | `0` |
| title | 按钮显示文案 | string | `''` |
| allow-reset | 是否允许循环回重置状态（0） | boolean | `false` |
| desc-first | 首次点击是否优先切换为降序 | boolean | `false` |
| line | 是否显示底部下划线（多按钮并排时通常关闭） | boolean | `false` |
| custom-class | 自定义类名 | string | `''` |
| custom-style | 自定义样式 | string | `''` |

## 事件（Events）

| 事件名 | 说明 | 回调参数 |
| :--- | :--- | :--- |
| update:model-value | 排序值变化时触发（v-model 更新） | value: `-1 \| 0 \| 1` |
| change | 排序方向切换完成时触发 | `{ value: -1 \| 0 \| 1 }` |

## 排序循环逻辑

组件根据 `descFirst` 和 `allowReset` 组合决定点击后的状态流转：

### descFirst = false（默认）
```
allowReset=false:  0 → 1 → -1 → 1 → -1 ...
allowReset=true:   0 → 1 → -1 → 0 → 1 → -1 → 0 ...
```

### descFirst = true
```
allowReset=false:  0 → -1 → 1 → -1 → 1 ...
allowReset=true:   0 → -1 → 1 → 0 → -1 → 1 → 0 ...
```

> 💡 **核心规则**：`allowReset=false` 时，状态在升序和降序之间无限循环，永远不会回到 0；`allowReset=true` 时，每次完整循环后回归初始态。

## 完整示例

### 多字段互斥排序
```vue
<template>
  <view class="sort-bar">
    <m-sort-button title="名称" v-model="nameSort" @change="onNameSort" />
    <m-sort-button title="价格" v-model="priceSort" @change="onPriceSort" />
    <m-sort-button title="销量" v-model="salesSort" @change="onSalesSort" />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const nameSort = ref(0)
const priceSort = ref(0)
const salesSort = ref(0)

// 切换某字段排序时，重置其他字段
function onNameSort() { priceSort.value = 0; salesSort.value = 0 }
function onPriceSort() { nameSort.value = 0; salesSort.value = 0 }
function onSalesSort() { nameSort.value = 0; priceSort.value = 0 }
</script>
```

### 优先降序 + 允许重置
```vue
<m-sort-button 
  title="综合排序" 
  v-model="sort" 
  desc-first 
  allow-reset 
/>
```

### 监听 change 事件获取排序详情
```vue
<m-sort-button 
  title="更新时间" 
  v-model="timeSort" 
  @change="(e) => console.log('排序方向:', e.value)" 
/>
```

### 带下划线的单列排序
```vue
<m-sort-button title="默认排序" v-model="sort" line />
```

## 注意事项

1.  **v-model 必填**：组件为受控模式，必须通过 `v-model` 或 `:model-value` + `@update:model-value` 绑定状态。未绑定时点击无效果。
2.  **互斥排序需手动实现**：组件本身不感知其他排序按钮的存在。多字段排序场景中，需在 `@change` 回调中手动将其他字段的值重置为 0。
3.  **line 使用场景**：`line=true` 适用于单独一行展示的排序按钮；多个按钮水平并排时应设为 `false`（默认），避免多余分割线干扰视觉。
4.  **图标语义**：上箭头高亮表示升序（1），下箭头高亮表示降序（-1）。两个箭头均不高亮表示未排序（0）。图标名称内部硬编码为 `caret-up` / `caret-down`，如需更换请覆盖 CSS 或 fork 修改。
5.  **active 样式类**：文字区域在非 0 状态下添加 `.is-active` 类，图标分别通过 `.m-sort-button__icon-up--active` 和 `.m-sort-button__icon-down--active` 控制高亮。自定义主题时可针对这些类名调整颜色。
6.  **虚拟宿主**：启用了 `virtualHost: true`（头条小程序除外），不会生成额外包裹节点。`custom-class` 和 `custom-style` 直接作用于根 `<view>`。
7.  **样式隔离**：`styleIsolation: 'shared'` 允许外部样式穿透。若全局样式意外影响排序按钮，请检查 `.m-sort-button` 相关选择器冲突。
8.  **无障碍提示**：组件未内置 ARIA 属性。在 H5 环境中建议在外层补充 `role="button"` 和 `aria-label` 以提升可访问性。
9.  **点击区域**：整个组件区域均可点击触发排序切换，不仅限于箭头部分。若需缩小热区，可通过 `custom-style` 调整 padding 或在外部包裹容器限制尺寸。
10. **类型安全**：`SortButtonValue` 严格限定为 `-1 | 0 | 1`，传入其他数值虽不会报错但会导致状态流转异常。业务层应确保数据源类型正确。
